| 页面/模块 | 接口 | 权限/缓存 |
|---|---|---|

## 关键处理

1. **分类与链接**：使用真正的树形接口，遍历四级分类；以 id 找名称/slug，避免把 id 当 slug。多级菜单使用原生 disclosure，支持触摸、键盘、Escape 和站内跳转收起；栏目过多时进入“更多栏目”。
2. **代理**：保留查询串；只向配置后端转发，阻止跨站写入；逐个转发 Cookie，刷新令牌从 JSON 中剔除；浏览器 Cookie 名称独立于旧前台。
3. **会话**：并发 401 共用刷新 Promise；启动恢复可兼容 StrictMode；注销和切换账号使旧请求失效，不把旧资料写回新账号缓存；清理私有缓存时保留已挂载的公开文章流。修改密码后重新登录；退出登录携带后端要求的访问令牌并撤销刷新会话。
4. **阅读**：正文与目录来自同一 Markdown 树，中文、行内格式和重复标题一致；原始 HTML 不执行，JSON-LD 安全转义。复制操作使用真实剪贴板并反馈失败。
5. **连续加载**：每批 10 篇，首屏服务端渲染，自动追加最多两批后转手动加载；按 id 去重，失败可重试，Footer 可达。另保留正常分页入口。
6. **故障区分**：核心数据失败进入恢复界面；只有真实 404 才显示不存在；侧栏等可选模块独立降级，不用空数组冒充核心请求成功。
7. **平台缓存**：标准 Next 使用原生缓存；Worker 使用独立 R2 增量缓存和直接重新验证。两种运行环境均实测设置变更到期可见，测试后恢复。

## 设计稿与真实契约的差异

| 设计示意 | 实际处理 |
|---|---|
| 焦点、广告、精选管理 | 后端没有独立运营位接口；放新项目类型化配置，不增加后台功能 |
| 收藏时间、点赞时间 | 端点没有提供，显示真实文章日期，不伪造用户操作时间 |
| 作者介绍/统计 | 仅显示端点实际提供的公开字段，不虚构履历或粉丝数 |
| 周热门榜 | 没有周榜接口，明确显示“累计阅读” |
| 邮箱清空 | 后端不接受空邮箱；表单留空保留原邮箱，并明确说明 |
| 收藏状态 | 没有独立状态端点，遍历收藏分页获取真实状态，不只看第一页 |
| 我的点赞分页 | API 返回数组，前端按每页 10 条分页 |
| 草稿和待审核文章 | 会员列表显示状态，避免链接到不可公开访问的详情 |
| 手机广告 | 独立 `mobileImage`，无素材时使用可读的浅蓝文字横幅 |

没有增加第三方登录、找回密码、关注、付费或广告管理等未支持业务。
