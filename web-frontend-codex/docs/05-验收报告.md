## 缓存检查

公开数据重新验证周期为 60 秒。临时改变独立测试库的站点描述，标准服务在约 70 秒、Worker 在约 71 秒取得新描述；随后恢复原值。首次过期请求允许返回旧内容并触发后台刷新，后续请求取得更新。

Worker 配置了独立 R2 增量缓存；本地模拟运行中曾有一次后台重新验证连接中断日志，后续请求正常更新。私有代理响应固定 `private, no-store`，访问令牌不落磁盘、不进入服务端公共页面数据。

## 验收中发现并修复

1. 会话恢复时清空全部 Query 缓存，可能使已挂载的首页文章流停在加载状态。修正为保留公开文章流、只清除其他查询，并在真实浏览器验证加载到结束。
2. 错误边界只做客户端 reset，无法重新获取失败的服务端结果。修正“重新加载”为完整页面重试，已通过停止/恢复后端的故障注入验证。
3. 草稿封面不再链接到公开 404；邮箱空值按后端约束处理；会员菜单补充站内跳转、外部点击与 Escape 收起；未读通知全部标记后正确回到首屏。
4. 浏览器验证发现旧认证封装在退出时省略访问令牌；后端要求鉴权，已修正并增加客户端封装回归测试。
5. 代理查询串、分类树路径、点赞状态路径、刷新 Cookie 隔离、重复中文目录锚点等契约问题已修正并纳入测试。
