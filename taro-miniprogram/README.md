# Taro 小程序 · 准备与技术验证

当前为验证工程，不是完整产品。Taro 4.3.0 + React 18 + TypeScript，依赖用 pnpm 锁定。

```sh
pnpm install
pnpm typecheck
pnpm build:weapp
```

在微信开发者工具导入本目录，源码输出为 `dist/`。配置 `urlCheck: false`；如工具的本地项目设置覆盖它，请在「详情 → 本地设置」勾选不校验合法域名。

当前使用 `touristappid`，只用于不依赖微信身份的验证。真实登录必须改为自己的 AppID，AppSecret 只能配置后端，不得写入此项目。

页面包含只读 API、手动测试账号登录/刷新、手动图片上传、基础排版及草稿保存恢复。不会自动注册账号、发表文章、发送评论或上传图片。上传需在页面显式启用，使用测试账号并记录清理的附件。

完整计划及每项验证状态见 `../docs/taro-miniprogram/README.md`。当前不以编译成功替代开发者工具运行验收。

## 本次导入（基础工程）

在微信开发者工具选择「导入项目」，目录选择本文件所在的 `taro-miniprogram`，不要选择仓库根目录或 src。工程配置已指定 miniprogramRoot 为 dist/，本地构建产物已生成。

AppID 可填写自己的小程序 AppID；尚未准备好时使用工具提供的测试号/游客方式（受工具权限限制，不用于真实微信登录）。不使用云开发，接口连接现有后端。导入后在「详情 → 本地设置」勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。

点击编译，应进入「成为全栈开发者」启动页，显示“基础工程已就绪”；点击“验证线上文章接口”可读取三条文章。技术验证台保留为辅助页面。网络验证失败会显示错误，可检查网络与域名校验设置。

本轮仅完成启动页和工程构建，不代表完整页面、微信登录或开发工具运行已验收。等待用户导入后继续。修改源码后需重新 pnpm build:weapp，持续开发可用 pnpm dev:weapp。
