# 成为全栈·Flutter App 篇·主题与可访问性：深浅色、大字号和触控体验

> 视觉与可访问性不是发布前最后加的一层。若布局只在默认字号和浅色模式下成立，用户一切换主题或放大文字，关键操作就可能看不见。

{{IMG:M4-25-封面}}

## 本文目标

结合 Flutter 项目主题系统和设备尺寸检查，说明跟随系统/浅色/深色选择、大字号布局、对比度与触控目标的实现和验证边界。

## 前置知识

了解 Flutter ThemeData 与语义化 Widget。主题构造位于 `app/theme/`，偏好设置在会员设置页面。

## 用户选择需要覆盖系统默认

项目支持跟随系统、浅色和深色三种模式，并持久化用户选择。跟随系统是默认策略，不等于“永远浅色”。切换主题只影响绘制，不应清空路由、文章、滚动位置或正在编辑的文本。

```text
ThemeMode.system / light / dark
→ ThemeBuilder 选择 ThemeData
→ ThemeExtension 提供产品语义色
→ Widget 使用语义而非硬编码色值
```

## 可访问性要覆盖内容细节

正文链接、引用、代码、表格、错误文案和输入框都要在两种主题可辨识。仅背景变暗而正文仍用浅灰，会让代码注释对比过低；仅凭色彩区分成功和错误，色觉差异用户也可能难以理解。

文字放大后，按钮标签应换行或调整，不应使用固定高度裁切；图标要有语义标签，不能只提供视觉形状。触控目标应考虑手指操作，而非只按图标绘制尺寸计算。

{{IMG:M4-25-主题矩阵}}

## 小屏验证要和大字号组合

项目记录在 320–430dp 宽度和 1.3 字体比例下做过布局检查。它证明这些指定视口/比例经过测试，不代表所有 Android 字体设置、平板折叠态或 iOS 辅助技术都通过。长标题、无头像、无封面、超长分类和表格比理想内容更容易暴露溢出。

Widget 测试适合检查断言和溢出，截图/模拟器检查视觉结果，真实设备与 TalkBack/VoiceOver 才能验证平台读屏和系统控件行为。

## 测试矩阵避免只看“亮/暗”两张截图

可以把验收条件拆为内容、主题、窗口和输入倍率的组合，而不是只截首页：

| 维度 | 至少检查 |
|---|---|
| 内容 | 正文代码、表格、评论、表单错误 |
| 主题 | system、light、dark |
| 窗口 | 320、375、430 dp |
| 字体 | 默认与项目已测的 1.3 倍 |
| 操作 | 触控目标、焦点顺序、语义标签 |

这张表有助于挑选有代表性的组合，并非声称项目已覆盖所有笛卡尔积。优先测试会改变布局结构的边界：窄屏 + 长标题 + 大字体，深色 + 代码块，错误态 + 输入焦点。颜色 token 的单元断言、Widget 溢出测试和真机读屏各自补足不同证据。

## 字体缩放策略不能靠统一压小字

Flutter `TextScaler` 会影响文本高度和换行。项目在 AppLayout 对最大缩放倍率有产品限制，同时测试 1.3 倍字体；这是一种体验取舍，并不等于系统字号完全无限放大。限制应在应用级统一应用，不能由页面分别缩小标题来“塞回原来的高度”。

需要对长按钮文字、字段错误提示、通知卡片和 Markdown 代码检查换行；代码通常保持横向滚动，普通正文则应随字号纵向扩展。图片替代文本和图标语义也应纳入 TalkBack/VoiceOver 真机验收计划。

## 设计令牌中有一项重要取舍：系统字体上限

当前 `AppLayout.maxTextScale` 为 1.3，通过 MaterialApp builder 统一夹紧系统文字缩放。它让原型在目标小屏保持结构，也意味着用户无法获得无限放大。文章应透明讨论这个选择：发布前可结合目标读者的可读性重新评估上限，并优先让容器高度自适应、允许换行，而非继续压低字号。

项目触控目标下限令牌为 44dp，页边距为 16dp；实际控件若图标视觉小，也可用透明 hit area 扩大触控区域。Accessibility inspector、TalkBack/VoiceOver 和键盘焦点路径仍需真实平台验收，不因尺寸 token 存在就宣称自动达标。

## 主题验收还要经过进程重启

用户选择深色后，Session 将 themeMode 存入 SharedPreferences；重启应用再恢复该值，才能证明设置不是仅存在于当前 Widget State。跟随系统模式则要切换 OS appearance 验证，不应被上次显式浅色/深色选择覆盖。

主题截图优先固定内容、模拟器像素密度和系统栏状态，避免不同数据长度造成误判。颜色对比度可以自动计算，但正文图像本身不应被强行反色；代码 token 在主题切换时重新映射样式，而不是沿用旧色值。

## 小结

主题选择、语义色、文字缩放和触控体验相互影响。将主题规则沉淀在 ThemeData/ThemeExtension，避免组件硬编码；用多宽度、长内容和大字号验证。已测的设备范围要明确，不能以通过模拟器截图代表无障碍全面验收。
