# M7 系列 CSDN 发布约定

- 发布或更新 M7 文章前，读取本目录 `M7-csdn-publications.json`；它记录编号、源文件和真实远端文章地址，以及用户确认的发布偏好。
- 已有 articleId 的文章应编辑原文章，不重复新建。线上修改先读取当前版本，只修改授权内容，保留用户调整过的标题、标签、摘要、封面和发布配置。
- 发布前检查正文和延伸阅读中的 M7 编号、上下篇引用：目标已经发布时，使用记录中的 URL 生成标准 Markdown 链接；未发布时保留普通文字，并记录待回填关系。不能编造 URL。
- 每篇发布成功后立即记录真实 articleId、URL 和源文件；区分提交成功、审核中与公开可访问。不得仅凭点击按钮记录成功。
- 新文章发布后，检查之前文章是否引用它，补齐本地前向引用；线上回填应在用户授权范围内执行。
- 同步修改本地引用，图片仍保留本地相对路径；上传时只在发布副本中替换图片地址。
- 更新前核对原创、AI 辅助声明、指定专栏、全部可见、默认模板、多平台发布为否。GitCode 备份在编辑页面可能默认不勾选，按用户要求在本次提交时勾选。
- 提交前核验编辑器正文与预期内容一致，避免富文本编辑器追加或重复正文。核对全部待补链接及其目标，保留未发布引用清单。
- 不自动提交 Git。此约定不授权自行发布；发布篇数和范围以用户当前任务为准。
