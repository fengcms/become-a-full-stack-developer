## 4. 架构亮点（本轮最值得肯定）

### 4.1 🔒 自锁保护（真实 footgun 被拦）
`UserEditDialog`（`:70-81`）：编辑**自身**账号时，`statusOptions` 的 `disabled` 选项被禁用并提示「你正在编辑自己的账号，禁用选项已锁定以防自锁」。禁用自己 = 无法登录/刷新 = 锁死后台——这是会**静默发生**的运维灾难，前端显式拦掉。是本轮最有价值的架构判断。

### 4.2 契约守卫测试继续加厚（防回归）
- `users.test.ts`(4)：钉死 `/users`（非 `/admin/users`）、`PATCH /users/{id}`、reset-password 路径 + 反向断言 `{ list, pagination }` 无 `items`/`total`。
- `site.test.ts`(2+2)：钉死 `getSiteStats→/stats`（注释明确 `not.toContain('categories')` 防与 `/categories/stats` 串味）、`getCategoryStats→/categories/stats`、`getAdminSiteSettings→/admin/site/settings`（注释解释不能用 `not.toContain('/site/settings')` 因路径自身含该子串，靠 `/admin/` 段区分）。
- 这类测试的价值不在「覆盖率」，而在**锁死契约真相、防后人误改**——符合本项目「契约冻结铁律」的正确工程化落地。

### 4.3 语义令牌纪律延续（P3-3 整改生效）
`index.css` 新增 `role-admin/editor/member` 与 `user-status-active/disabled` 双主题令牌（`:68-77` 浅 / `:140-149` 深）+ `@theme inline` 映射 `:205-214`。组件用 `bg-role-admin text-role-admin-fg` 等，暗色自动「深底+亮字」。`DashboardPage` 状态色亦走 `bg-status-draft`/`bg-status-approved`。

### 4.4 写后失效键正确
`useUsers`：`invalidateQueries({ queryKey: ['users'] })` 前缀匹配 `qk.users.list(q)`（首元 `'users'`）；站点设置 `invalidateQueries({ queryKey: qk.site.adminSettings })`。写后列表回最新，无脏读。

### 4.5 零回归
- **新增依赖**：无（recharts `^3.10.1` 在计划 Phase 5 已规划，非本轮引入）。
- **localStorage**：本轮无新增（仍仅 `auth.ts` 不落凭证 + `ui.ts` 侧栏态）。
- **chunk 体积**：未膨胀；recharts 仅由路由级 `lazy` 的 `DashboardPage` 承担（336.47 kB / gzip 99.07），不影响首屏。
