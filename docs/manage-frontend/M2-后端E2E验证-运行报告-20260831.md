## 残留数据说明

- 注册的两个 member 账号（一个被提升为 editor、一个保持 member）**无法经 API 删除**（契约无 DELETE /users 端点，v1 设计为软禁用）。标识：username 含 `e2emember` / `e2emem2` + 时间戳。如需清理请后端 owner 手动禁用或后续补删除端点。
- 文章/评论/标签/附件均已自动清理；分类若被引用删除策略放行亦已随之消失，删除步骤对 404 容忍。
