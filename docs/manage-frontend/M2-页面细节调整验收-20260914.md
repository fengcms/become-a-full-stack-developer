# M2 页面细节调整与验收

日期：2026-09-14。依据同目录《M2-页面细节代码审阅与建议-20260914》。保留导航、整体布局与视觉基调；未修改后端、冻结接口契约或依赖清单，未提交 Git。

## 已实现

| 范围 | 调整后的行为 |
| --- | --- |
| 写作与保存 | 普通保存保留文章当前状态；发布与下架分开。保存后留在编辑页，新建成功转为编辑已有稿件；显示待保存、上传中和保存结果。 |
| 输入保护 | 文章、站点设置、个人资料增加路由离开与窗口关闭提醒。首次加载失败显示重试；后台重新获取不覆盖当前输入。 |
| 图片与编辑器 | 统一感知上传任务，上传期间禁用提交；预检类型与 10MB 限制。连续插图使用最新正文，切换面板保留编辑器；小屏默认单栏。 |
| 文章设置 | 横向封面预览，分类显示父子路径，标签已有项联想，支持中文逗号与输入法组合状态判断；校验失败定位相应面板。 |
| 列表与批量 | 分类筛选、清除条件、标题入口；编辑返回保留页码及筛选。选择限于当前页，切换条件清空；批量审核只作用于待审文章，汇总结果并保留失败项。 |
| 评论 | 审核动作使用“通过／拒绝／待复核”，按动作显示理由。按需加载文章标题，提供只读预览与父评论编号；被过滤的回复保留正文。 |
| 分类与标签 | 分类搜索保留祖先路径，可展开／收起；标签搜索、使用量排序，文章数链接至对应文章列表。 |
| 用户与站点 | 当前管理员不能通过角色选择自我降权。站点设置分品牌、搜索展示、页脚，提供预览及撤销修改；保存刷新品牌缓存。 |
| 个人中心 | 收藏、点赞增加只读文章入口；收藏删除后刷新并恢复有效页码，点赞提供翻页。通知可展开全文，识别的文章链接映射到预览。 |
| 仪表盘与文案 | 增加写作和待处理入口，近期内容可点击；错误与空数据分开，减少直接暴露接口和状态枚举的文案。 |

共用逻辑拆至上传作用域、离开保护、批量选择、搜索同步等组件／Hook；文章表单映射与表格列独立维护。

## 浏览器实测

使用独立临时数据库与本地服务：前端 12010、后端 11010。原有 12000／11000 服务和数据库未用于写入验收数据。

1. 新建保存后停留编辑页；发布缺分类时切换设置并提示；已发布文章修改后仍为已发布。
2. 侧栏跳转、浏览器返回时出现未保存提醒，继续编辑保留正文。
3. 连续粘贴两张图片均插入正文，保留原内容；上传期间提交禁用；封面上传与预览正常。
4. 列表第二页进入编辑再返回，保持第二页；切页清除选择；草稿不能执行待审文章批量审核；待审文章批量审核成功。
5. 评论审核显示文章标题，选择待复核后出现备注并能保存。
6. 站点设置保存后恢复无修改状态，侧栏品牌同步刷新。
7. 390px 窄屏无页面横向溢出，编辑器改为单栏；1280px 下封面及设置布局正常，查看了浅色与深色界面。
8. 验收首页控制台无错误或警告；浏览器尺寸覆盖已恢复。

## 验证边界

本轮不是完整跨浏览器自动化验收。真实中文输入法组合、刷新／关闭窗口提示、精确控制上传中打字的竞态、批量部分失败与内容过滤拒绝回复尚未逐项做浏览器故障注入；相关代码已调整，不能视为全部实测通过。离开保护不等同于自动保存，不承诺退出登录或会话失效后恢复稿件。

未加入本地草稿自动恢复、分类拖拽排序或新后端能力。长内容与不同屏幕的视觉细节可根据实际使用继续微调。
