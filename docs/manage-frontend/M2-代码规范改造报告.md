## 一、确立的规范（`docs/manage-frontend/开发规范.md`）

1. **文档归位**：所有 `manage-frontend` 相关文档一律写 `docs/manage-frontend/`，不得散落他处。
2. **箭头函数优先**：禁止 `function` 声明，全部 `const fn = () => {}`（含 React 组件、含 `export`）。
3. **文件头注释**：每个源文件顶部必须有 `@file/@description/@module/@date` 说明。
4. **函数级 TSDoc**：每个函数（导出/内部）都要有 `/** */` 注释，带参/返回的写 `@param/@returns`。
5. **单文件 ≤ 200 行 + 单文件单职责**：超长须文件头注明原因；页面组件尽量拆子文件。
6. **豁免清单**：`src/components/ui/*`（shadcn 生成）、`src/types/api.gen.ts`（契约生成）、`src/vite-env.d.ts`（Vite 资产）豁免箭头/TSDoc，但需保留来源头。
