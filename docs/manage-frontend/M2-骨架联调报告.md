## 四、发现的问题与处理

1. **`GET /site/settings` 线上返回 5000**（站点设置行未种子）。属后端数据问题，非前端路径错。
   处理：前端 `usePublicSiteSettings` 加 `retry:false`，侧栏品牌名回落「全栈后台」，不崩溃。
   建议：owner 在后台「站点设置」页填一次，或后端对该端点缺行时返回默认值。

2. **Secure Cookie 在 `http://localhost` 不回传**（浏览器/curl 对 `Secure` Cookie 不在 http 回传）。
   影响：基于 Cookie 的「刷新页面静默恢复会话」仅 HTTPS（生产）生效；**开发期靠内存 refreshToken（请求体）保活**，刷新页面需重新登录（dev 已知限制）。
   可选方案（待 owner 定）：① 接受 dev 重登；② 开发服务器上 HTTPS；③ 后端按环境对 dev 不去 `Secure`。

3. **副作用账号**：联调时注册了探针会员 `probe_member_x`（最低权限）于线上库。请用 admin 凭据删除或确认保留。
