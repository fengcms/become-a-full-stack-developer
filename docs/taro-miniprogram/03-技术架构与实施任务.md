# 技术架构与实施任务

> 历史准备文档。2026-10-07 已进入参考 APP 的实际开发，最新状态见 [开发交付与验收记录](implementation/02-开发交付与验收记录.md)。本文的待开发/待验证状态仅对应准备阶段；复杂微信绑定流程和单独 HTML 确认门槛已被后续决策替代。


## 工程约定

独立目录 `taro-miniprogram`，Taro 4.3.0 全家桶同版本，React 18（遵守插件 peer 范围）、TypeScript。Webpack5 构建微信目标，pnpm 锁定依赖。先输出 weapp，不同时拉入无需求的 H5/其他小程序平台。

正式目录：app（启动/主题）、pages（薄页面）、features（阅读/互动/会员/投稿）、services（请求/认证/上传）、models（契约生成）、storage（缓存/草稿）、components（语义组件）、platform（微信能力）。验证台位于 pages/lab，正式入口上线前从普通导航移除。

请求层：统一信封、超时、401 单飞刷新、刷新后重放一次、会话代际隔离。写请求不自动重试；上传单独适配字符串响应与取消操作。环境变量控制 API 根地址，凭据和 AppSecret 不进构建产物。

缓存：公开文章列表/正文限时复用，前台返回恢复列表和滚动；私有数据按环境+userId+session epoch 隔离，第一期仅内存。主动刷新强制回源；点赞收藏乐观更新并同步列表，失败回滚；404/权限变化驱逐。图片依赖平台缓存，不假定自有数据缓存能控制图片存储。草稿独立于可清除缓存，按账号+稿件区分，明确恢复与丢弃。

正文：先验证小程序可用 Markdown AST → 受控组件树的方案，代码语言与高亮按需加载；不执行原始 HTML/脚本。长表格/代码横滑，目录与渲染标题对应，外链单独拦截。完整编辑器以 textarea + 工具条 + 预览为候选，不嵌入桌面 DOM 编辑器。

## 阶段与任务

| 阶段 | 任务 | 退出条件 |
|---|---|---|
| P0 准备 | 文档、后端差异、平台资料、工程脚手架 | 范围与待验证项可追踪 |
| P1 技术验证 | API、登录刷新、上传、长文、草稿、目录与缓存 | 每项附环境和证据；不以编译代替运行 |
| P2 全页面设计 | 页面地图全部 HTML 原型、主题、错误和授权状态 | 用户确认全套页面 |
| P3 认证后端 | 冻结 OpenAPI、迁移、微信交换/绑定、兼容回归 | 本地 + D1 环境测试通过；配置后微信实测 |
| P4 阅读 | 首页/列表/搜索/详情/目录/缓存/分享 | 开发工具阅读闭环 |
| P5 会员 | 登录/资料/收藏点赞历史/通知/评论 | 私有隔离、互动回滚通过 |
| P6 投稿 | 列表/编辑/上传/草稿/预览/提交 | 失败保输入与跨页恢复通过 |
| P7 验收 | 自动测试、类型检查、weapp 构建、工具全链路 | 证据归档与限制说明 |

P1 与 P2 可交错；P3 需先冻结身份契约；不在 P2 确认前全面实现 P4～P6。此轮完成 P0 与 P1 基础工程，后续状态以验证记录为准。

测试分层：纯逻辑单测（缓存/草稿/身份状态），API 合约测试，开发工具交互回归。CI 检查类型、构建、测试；真机与上架不设必过门禁。正式开发延续 Flutter 审阅经验：小组件、明确输入、业务与展示分离、按实际语法统计复杂度。

## 测试数据

线上匿名 GET 可用于连通性；写操作必须使用明确测试账号与内容。测试附件、草稿、评论记录 ID 并清理，不删除真实内容。不得自动创建生产管理员、修改角色或批量清缓存。完整登录测试不收集密码到文档，配置通过本机界面或安全环境输入。
