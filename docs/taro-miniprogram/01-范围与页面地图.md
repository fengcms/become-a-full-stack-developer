# 范围与页面地图

> 历史准备文档。2026-10-07 已进入参考 APP 的实际开发，最新状态见 [开发交付与验收记录](implementation/02-开发交付与验收记录.md)。本文的待开发/待验证状态仅对应准备阶段；复杂微信绑定流程和单独 HTML 确认门槛已被后续决策替代。


## 产品基线

沿用 Flutter 已确认的清爽白/浅蓝底、深色正文、蓝色点缀和原型图标语义；深色模式独立配色。参考 `docs/flutter-app/prototype/02-高保真可交互原型.html`，不直接复制 Flutter 布局代码。小程序胶囊、顶部安全区、系统返回与底部入口需重新适配。

四个主入口：首页、分类、搜索、我的。主入口保留列表和滚动状态；详情使用页面栈，分享入口可直接进入文章。

| 页面 | 核心交互与状态 |
|---|---|
| 首页 | 焦点手动轮播、最新、热门、分页；骨架、缓存旧数据、重试 |
| 分类/标签/筛选结果 | 树形分类、标签筛选、清空条件、空结果、翻页 |
| 搜索 | 历史词、热门标签、提交搜索、清空历史、关键词切换、结果返回恢复 |
| 文章 | Markdown、代码语言/高亮/复制、横向表格、图片预览、目录定位、作者、上下篇 |
| 文章互动 | 点赞收藏乐观更新与失败回滚、分享路径、叠楼评论、登录回跳、键盘收起 |
| 作者主页 | 公开资料与文章分页；作者禁用/不存在 |
| 登录 | 微信登录、已有账号登录、注册；拒绝/失效/恢复中/后端未配置 |
| 微信初次绑定 | 创建新会员或验证已有会员；已绑定冲突，不静默合并 |
| 会员首页 | 资料、统计、最近历史、登录失效 |
| 收藏/点赞/历史 | 私有列表即时同步、空状态、分页、账号切换清理 |
| 我的文章 | 草稿、审核中、已发布、拒绝原因、编辑/预览入口 |
| 投稿编辑/预览 | 标题、摘要、Markdown、分类标签、封面、上传重试、本地恢复、离开保护 |
| 通知 | 未读、标记已读、分页、失败恢复；站内通知，不等于微信订阅消息 |
| 资料与账号 | 昵称头像邮箱；是否已设置密码、微信绑定状态、设置/修改密码 |
| 设置 | 浅色/深色/跟随系统、缓存清理、退出、隐私说明、演示限制 |
| 通用状态 | 未知路由、内容不可见、网络失败、会话过期、上传失败、未保存提醒 |

第一期不包括手机号快捷登录、订阅消息、账号数据自动合并、支付、正式提交审核。

## 平台差异决策

- 外链：站内文章优先转换内部路由；其他链接展示地址并允许复制，不承诺任意网页可内嵌。游客 AppID 不作为 web-view 能力证明。
- 代码复制、图片预览、目录锚点、叠楼与长文输入必须专项验证。
- 原型以 HTML 展示所有不同页面，包含浅/深主题、登录/未登录、空/错/加载态和关键弹层。首页不替代全站设计确认。
- 真实微信身份缺失时显示明确说明及账号登录入口，不制造“微信登录成功”模拟状态。

设计验收：页面清单逐项对应原型路由，按钮可演示主要转换，超长标题、空列表、无头像、长代码/表格都有样例。用户确认后进入产品页面全面开发。
