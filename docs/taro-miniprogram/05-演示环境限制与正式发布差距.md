# 演示环境限制与正式发布差距

2026-10-07，按用户确认仅供教学演示。当前后端位于 Cloudflare，域名未备案，项目不以正式上架为目标。Cloudflare 本身不是此次排除上架的唯一判断依据；这里记录的是当前部署、域名条件与用户确定的范围。

## 本次成立的验收

微信开发者工具开启“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”相关调试选项后，项目能够编译、请求指定后端并完成约定业务，即作为本次验收。工具模拟器、版本、AppID 类型和选项状态须记录。桌面 curl、单测、构建成功只作辅助证据。

`project.config.json` 中 urlCheck=false 仅为演示配置，工具本地覆盖设置也须确认。无需为了本次开发去备案、换服务器、正式认证、上传审核或购买手机号额度。

## 该选项不会带来的能力

不会生成合法 AppID/AppSecret、不会实现尚未开发的微信后端认证，不会让虚构 openId 成为可信身份，不会自动赋予手机号/订阅消息/web-view 权限，也不会证明真机发行环境能联网。游客项目可以验证普通页面与业务请求，不能替代真实微信认证。

## 将来若发布，需要重新评估

主体与类目、平台当时的备案/认证要求、合法域名和证书、业务域名、隐私声明与实际数据使用一致性、用户内容审核与投诉处置、密钥与日志管理、真机兼容、包体及分包、后台恢复、性能和发布回滚。

以上为未来发布差距清单，不计入本次演示版本未完成任务；真实微信登录缺少必要配置则必须单独标为待验证，不能混进“上架已排除”而略过。
