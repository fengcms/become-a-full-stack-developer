# 微信线上配置与真实登录验收

2026-10-07。本记录更新前期“线上缺少微信密钥、真实微信登录未验证”的状态。

## 配置结果

用户在 `taro-miniprogram/.env` 提供两项配置。读取时只在进程内解析，核对 AppID 与 project.config.json 一致，通过标准输入批量写入 Cloudflare `node-backend` Worker：

- WECHAT_MINI_APP_ID
- WECHAT_MINI_APP_SECRET

Wrangler 报告两项上传成功，随后 secret list 确认两项存在，原 JWT_SECRET 保留。密钥不写进命令参数、文档或 Git。`.env` 已被现有 `.env*` 规则忽略，文件权限收窄为 0600；检查 Git 跟踪文件和 dist 构建产物，未发现 AppSecret 明文。用户提供的本机文件保留，没有删除。

## 联调发现及修复

密钥上传后，真实登录仍返回 500。加入只记录静态原因、HTTP 状态及上游数值错误码的诊断日志，确认失败发生在请求阶段。日志不包含 URL、异常原文、AppSecret、code、OpenID 或 session_key。

在兼容日期 2025-01-01 的本地 workerd 复现：`redirect: 'error'` 抛出 TypeError，运行时要求 follow 或 manual。原先 Node 测试模拟 fetch，因此未覆盖该运行时参数差异。

修改为 `redirect: 'manual'`，继续通过 `!response.ok` 拒绝所有 3xx 响应，不跟随跳转，不将微信凭据发到其他地址。没有修改 API 契约、数据库或身份模型。

新增回归验证：302 响应被拒绝、仅请求一次、不创建用户；诊断不含敏感内容。TypeScript 和微信相关 10 项测试通过。

已部署 Worker 版本：`b301e62b-5096-4533-a40f-5f6c84030f5c`。

## 线上验证

- 普通文章接口返回 code 0，配置未影响公开阅读。
- 故意无效的 code 返回 401 / 1002，替代修复前的 500，证明请求进入微信凭据校验流程；该探测不创建会员。
- 微信开发者工具点击“微信快捷登录”，使用工具真实 wx.login code 和线上 callback，成功返回会员中心。
- 界面显示“微信会员”、会员统计和“设置用户名和密码 → / 在网站和 APP 登录同一个账号”。这是实际身份认证结果，不是模拟会话。
- 保留当前会员登录状态。没有代用户设置密码，也没有发布测试文章、评论或修改用户角色。

本轮确认真实微信登录及首次凭据设置入口。重复登录是否复用同一 userId、实际设置用户名密码后 APP/网页登录同一账号，仍未做真实身份的全链路操作；对应后端逻辑已有自动化测试，不能混称真实跨端验收。
