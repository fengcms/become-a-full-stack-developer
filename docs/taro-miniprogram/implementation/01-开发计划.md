# 小程序实际开发计划

2026-10-07。用户已导入真实 AppID 的工程，明确授权参考 APP 开始开发；本轮不再把另行确认 HTML 原型作为前置门槛。沿用 Flutter 已确认的版式、图标、颜色和业务流程，适配微信导航及原生能力。

## 分段交付与提交

1. 基础：类型、请求与单飞刷新、会话隔离、限时缓存、主题、图标、导航和通用分页组件。
2. 阅读：首页、分类/标签、搜索、作者、详情、Markdown、高亮、目录、图片、分享与叠楼评论。
3. 会员：密码/微信登录、注册、首次账号设置、资料/改密、收藏/点赞/历史、通知、设置。
4. 投稿：我的文章、Markdown 编辑与预览、图片上传、按账号本地草稿、保存/提交/删除。
5. 验收：逻辑测试、类型检查、正式构建、微信开发者工具运行及问题修复、交付记录。

每个完成节点采用 Conventional Commits 中文说明提交。保留已配置 AppID，不保存 AppSecret。接口使用线上 api-befull.kao9.com；写验证限专用测试数据并清理，不修改真实内容。

## 工程决策

- Taro 4.3 + React 18 + TypeScript，不更换框架；复用 APP 原型 SVG 图标。
- 四个原生 Tab：首页、分类、搜索、我的；其他页面走页面栈。
- 公共数据与私有数据隔离。刷新请求单飞，旧账号异步响应不能覆盖新会话；写操作不因网络失败自动重试。缓存有界，草稿与缓存分开。
- 小程序外链提供复制地址，不承诺绕过微信业务域名限制内嵌任意网页。
- 微信登录仅调用 wx.login + 现有 callback；canSetCredentials 时允许一次性设置用户名密码。无身份模拟、无账号合并。
- 真实微信端到端登录取决于后端 AppID/AppSecret 配置；未配置时明确提示，并保留账号登录。
- 页面内提供加载、失败重试、空状态；深色与跟随系统均支持。
