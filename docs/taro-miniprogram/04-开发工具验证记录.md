## 工程位置与运行方式

导入仓库的 `taro-miniprogram` 目录，miniprogramRoot 为 dist/。先执行 pnpm install、pnpm typecheck、pnpm build:weapp。项目设置 urlCheck=false；工具的私有配置可能覆盖，须确认本地“不校验合法域名”选项开启。

验证页不是产品首页，没有把临时排版作为已确认设计。首个按钮只读文章，第二个只读分类。测试账号登录后可刷新 Token；清除按钮仅清空本机凭据，不误调用全端登出。图片上传需要手动确认使用测试账号，成功后记录附件并清理。草稿使用专属 m5.lab.draft.v1，不触碰现有 APP 草稿。

## 本轮遇到的问题

1. Taro 4.3.0 搭配自动解析出的 webpack 5.111.1，webpackbar 的选项被 ProgressPlugin 拒绝；锁定 webpack 5.98.0 后解决，未修改第三方包源码。
2. pnpm 严格依赖布局暴露 Babel preset 依赖缺失，已显式声明 preset-env/react/typescript。
3. 依赖安装脚本通过 pnpm-workspace.yaml 明确允许原生编译依赖，CLI/core-js 的非必要安装脚本未启用。
4. 微信工具 CLI 返回 service port disabled。未擅自开启全局安全设置；尝试通过原生界面查看窗口时截图超时。未能完成该工程导入与点击验证，因此不宣称工具验收通过。
5. 本机终端直连 API 超时，经已有本机代理只读成功。后续需在微信工具自身网络设置下复验，不把终端代理成功等同工具网络成功。
