## 已确认的工程取舍

1. 不嵌入 gorm.Model，不使用启动 AutoMigrate；通过显式 goose SQL 迁移。
2. 时间存储统一 UTC epoch 毫秒 bigint；对外显式转 ISO 字符串。这样可无损导入 Node 日期并减少驱动时区差异。
3. SQLite 初版采用单写连接与 WAL/busy timeout：符合单进程教学服务定位，并通过并发请求验证业务约束；不宣称高并发多实例能力。
4. 更新输入保留字段存在性；HTTP schema 验证后形成 Fields，领域服务显式白名单映射，避免零值被 ORM 忽略。
5. 冻结文件声明3.1但仍使用nullable；只在校验器内转换为JSON Schema anyOf，不修改契约文件。

## G3 文章与分类标签

- 实现文章公开/本人/后台列表、详情、创建更新、软删除释放slug、投稿与审核状态机。
- 文章和标签关系在同一事务维护；分类/标签变更同步文章展示投影。树结构限制4级并校验移动子树、成环与引用占用。
- 用例验证会员不能自发布或指定slug、非本人拒绝更新、未发布匿名404、非法前态409、删除后slug复用，以及分类深度/环/零值更新。
- SQL查询按白名单排序，发布时间为空用创建时间参与比较，尾部id DESC稳定分页；标签按照契约只按slug筛选。
- MySQL索引列显式使用有界VARCHAR，避免TEXT索引在真实迁移时失败。

## G4 评论与发现

- 实现评论发表/平面列表/复核/多层级联删除，搜索文章与会员、TOC、相邻/相关文章、阅读去重。
- 敏感词按JavaScript UTF-16长度计比率，代码围栏与重复目录锚点有纯函数测试。
- 冻结产品规则默认敏感词阈值10%，Node源码为30%；Go按10%实现并支持COMMENT_REJECT_RATIO配置，原Node不改写。
- 冻结产品规则为24小时冷却，Node时间桶可能跨午夜提前恢复；Go改为从首次计数起的滚动窗口，行锁保护去重记录及计数，验证午夜与并发边界。
- 请求评论允许65535字符但响应Comment限制2000，Go保留存储全文、展示最多2000字符（末位省略号）；reason响应限制200字符。长目录重复后锚点仍保证不超过100字符。均作为契约内部长度差异的明确处理，不修改冻结文件。
- 事务行锁能力下沉database包，文章/评论/会员不依赖认证领域的数据库机制。

## G6 附件与存储

- HTTP上传独立处理multipart：只接受一个文件、限定类型、10 MiB上限，临时文件及时清理。文件直出SVG使用attachment，其他类型inline，并保留nosniff。
- local实现使用受限key与原子重命名；R2使用AWS SDK v2的S3兼容接口、固定超时和签名。真实HTTP替身验证签名、PUT/GET/DELETE，未将替身冒充线上R2联调。
- 相同内容key允许多个元数据引用；删除仅在最后引用消失后删对象。元数据写失败时，已有引用的文件不得误删。按key分片锁保护本进程上传/删除竞争；跨实例对象删除仍需生产运维约束。
- SQLite附件共享key、数据库失败补偿、local路径保护与R2 HTTP替身用例通过。最终装配检查全部68操作已绑定，缺失R2配置启动失败。
