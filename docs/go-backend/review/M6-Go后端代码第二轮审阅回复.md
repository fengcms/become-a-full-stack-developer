## 3. 不采纳机械新增重复文档门禁

报告建议把“同名符号不同行为的文档不得逐字相同”机器化。我不把重复文本直接作为硬性失败：相同说明可能描述相同行为，不同文本也可能同时失实。函数行为和正确文档的对应关系仍需要人工核对，单纯字符串比较不能证明它。

本次按文件位置和接收者分别核查同名符号，修复具体错误，并把这项要求写入工程规范。原门禁的断言和阈值未调整。没有为补两处注释新增镜像单测或用计数器代替语义审阅。

另外，按同一输入复现静态日志是合理要求；运行测试的耗时、随机目录和请求标识并不具备逐字节重复性。因此证据分为静态输出一致性和运行检查结果，两者不混用。
