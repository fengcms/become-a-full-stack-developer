## 5. 本轮新发现（第一轮没有、且**门禁查不出**的问题）

> 门禁 `check_go_quality.go` 的「中文注释 ≥ 120」只数**含 CJK 的行数**。它保证「有中文注释」，**不保证「注释是对的」**。以下三条都在它的盲区里。

### 5-1　文档与实现不符（P2，但性质重要）

`internal/values/values.go:73`

```go
// Text 将字符串转换为指针，可空输入返回 nil。   ← 不成立
func Text(s string) *string { return &s }        ← 参数 string 不可为 nil，函数永不返回 nil
```

- **根因**：这段注释是从同文件 `:39` 的方法 `func (f Fields) Text(k string) *string` **逐字复制**的（该方法**确有** nil 分支，注释对它成立）。
- **伴生问题**：同名符号（方法 `Fields.Text` 与包级 `Text`）拥有**完全相同**的文档，但**行为不同**。教学代码里这会让读者把两者当成同一个东西。
- **为什么值得单独列**：它是 A-3「补齐导出文档」推进过程的**副产品**——为了让「导出符号缺文档 = 0」，把已有文档复制过去，**计数器绿了，但引入了错误**。这是「为达成指标而牺牲正确性」的最小可复现样本。

### 5-2　同文件同名符号文档重复且前一条失实（P2）

`internal/article/query.go:27` 与 `:52` 两条文档逐字相同：`// Get 按 ID 或 slug 获取未删除文章；服务方法还检查访问者可见性。`

- 后一条（`:52` 方法）**准确**。
- 前一条（`:27` 包级函数）**失实**：包级 `Get` 只做查询，**不**检查可见性（可见性判断在 `:53` 方法里）。

### 5-3　中文注释体系中残留 9 条英文内联注释（P3，一致性）

`auth/wechat.go:107`、`platform/database/metrics.go:14-16`、`platform/database/database.go:96-97`、`values.go:122`、`transfer/snapshot.go:2,137`、`cmd/seed/main.go:1`、`cmd/data/main.go:55` 共 9 条英文散文注释，散在一个已经中文化的代码库里（`//go:embed` 指令行不计）。包级文档保持英文**可接受**（Go 惯例，第一轮已认可）；内联散文注释中英混排则**没有统一口径**。

### 5-4　A-11 同类未列项 3 处（P3）

`attachments.go:32`（固定 MIME 表）、`attachments.go:69`（固定白名单）、`article/query.go:68`（固定排序列白名单）——仍是「固定查表每次调用重建」。**这不是工单未完成**（A-11 当时只点名了 `fault`/`values`），属同类现象的另一批样本。另有约 28 处 map 字面量是每次调用**必须**新建的累加器（`seen`/`ids`/`by`/`patch`），不属此列。

### 5-5　证据可复现性的一处小漂移（P3，证据卫生）

| 日志 | 作者保存值 | 我在 `9590cb1` 复跑 | 差 |
|---|---|---|---|
| 生产代码门禁 | 70 文件 / 5774 行 / 221 函数，最长 79，嵌套 4 | **完全相同** | 无（逐字节可复现） |
| 含测试代码门禁 | 93 文件 / **8002** 行 / >120 行 **32** | 93 文件 / **8007** 行 / >120 行 **33** | 5 行 / 1 条长行 |

- 说明含测试日志抓取自**最终提交之前**的工作区状态。不影响任何结论（含测试 4 项未过与这些数字无关），但「已保存日志应能在冻结提交上逐字节复现」是证据纪律。

## 6. 评审方自我订正

按惯例，记录我这轮**自己**的错与口径修正（每条可复现）：

1. **我第一轮的一个论据站不住**：我写「`e` 命名……将来用 `errcheck` 等工具时会格格不入」。作者指出我没有证据表明**变量拼写**影响错误检查工具——他是对的。`errcheck` 检查的是**未处理的错误返回**，与变量叫什么无关。该论据我**撤回**；`e`→`err` 的正当理由只剩「社区共识 + 同函数内 `err`/`e` 混用造成遮蔽」，而这**已经足够**，不需要工具背书。
2. **我的「重复文档检测器」第一版漏报**：它用 `文件:符号名` 作去重键，导致 `values.go` 里**同文件同名**的 `Text`/`Text` 被判为同一项而**漏掉**。补上行号后才现形（§5-1）。→ **去重键必须包含位置，否则「同名不同物」会被合并掉**。
3. **本轮我刻意不重复第一轮的方法论错误**：第一轮我把结论建立在单一自写门禁上（「这把尺子说绿」）。本轮我加了一把**算法迥异**的独立尺子（括号深度）来重算核心指标，两把同报才算数。
4. **我把「门禁绿」与「结论成立」明确切开**：13/13 绿**不等于**该维度做对——§5-1/5-2 两条缺陷是在**门禁全绿**的情况下由**人工阅读**发现的。
