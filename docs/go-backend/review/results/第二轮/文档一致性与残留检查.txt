二、缺陷 1：文档注释与实现不符（门禁无法发现）
======================================================================
  internal/values/values.go:73
    // Text 将字符串转换为指针，可空输入返回 nil。
    func Text(s string) *string { return &s }

  问题：参数类型为 string（不可为 nil），函数体直接取址、永不返回 nil。
  「可空输入返回 nil」与实现不符——它是从同文件 :39 的方法
  「func (f Fields) Text(k string) *string」（该方法确有 nil 分支）原样复制的。
  两个同名符号（方法 Fields.Text 与包级 Text）拥有逐字相同的文档，
  而行为不同。这是 A-3「补齐导出文档」推进中产生的复制粘贴错误。
