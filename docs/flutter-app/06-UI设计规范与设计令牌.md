## 1. 设计原则

1. **正文优先**：移动端首要是可读。文章正文是唯一允许使用最大行高（1.85）与最大字号（17sp）的区域，装饰元素一律让位。
2. **白底主导、主题色点缀**：主题色只用于链接、选中态、关键按钮与图标，不铺大面积底色。深色模式同理，用低亮度蓝而非高饱和亮蓝。
3. **结构表达状态，颜色只是辅助**：`pending` 状态必须同时有文字标签 + 图标，不能只靠黄色底传达（可访问性硬要求）。
4. **触控优先**：所有可点击元素最小 44×44dp 命中区；列表行高不小于 56dp。
5. **令牌先行**：同一种视觉元素全站只有一个定义。底部导航、卡片、输入框、徽章均为「一处定义、多处复用」。

## 3. 字体层级

字体族：`PingFang SC` → `Noto Sans SC` → 系统无衬线（`fontFamilyFallback`）。**不请求外部字体**，包体内不塞中文字体文件。等宽：`SFMono-Regular` / `Roboto Mono` / `monospace`。

| 令牌 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| `type.display` | 24 | 1.35 | 700 | 焦点文章标题、空态主标题（≥600dp 可升至 28） |
| `type.h1` | 24 | 1.4 | 600 | 页面主标题、文章详情标题 |
| `type.h2` | 20 | 1.45 | 600 | 区块标题 |
| `type.h3` | 17 | 1.5 | 600 | 列表项标题、卡片标题 |
| `type.reading` | 17 | 1.85 | 400 | **文章正文（唯一）** |
| `type.body` | 15 | 1.7 | 400 | 常规正文、表单值 |
| `type.label` | 14 | 1.5 | 500 | 按钮文字、Tab 文字 |
| `type.caption` | 13 | 1.55 | 400 | 摘要、说明、表单辅助 |
| `type.micro` | 11 | 1.4 | 400 | 时间、计数、徽章 |

规则：

- 字号单位统一用 **sp**（随系统字体缩放）。Flutter 的 `fontSize` 使用逻辑像素，实际缩放由 `MediaQuery.textScaler` 承担；实现必须配置可访问的文本缩放，并用 `maxLines`、`ellipsis` 或横向滚动保证 `type.reading` 在放大到 1.3 倍后不横向溢出。
- 标题字重上限 700，正文只用 400/500，不用细体。
- 中文不设负字距；数字与英文走同一套（不额外换字体）。
- 用户稿件长文（65,535 字符上限）必须走 `type.reading`，不得降级。

## 4. 间距、圆角、阴影、描边

### 4.1 间距刻度（4 基准）

| 令牌 | 值 | 典型用途 |
|---|---|---|
| `space.1` | 4 | 图标与文字间隙、徽章内边距 |
| `space.2` | 8 | 元素内间隙、标签间距 |
| `space.3` | 12 | 卡片内边距（紧凑）、列表行内间隙 |
| `space.4` | 16 | **页面左右边距**、卡片内边距 |
| `space.5` | 20 | 区块内边距 |
| `space.6` | 24 | 区块之间 |
| `space.8` | 32 | 大区块之间 |
| `space.10` | 40 | 页面顶／底留白 |

移动端页面左右边距统一 `space.4`(16dp)；表格、代码块允许贴边但内部保留 `space.3`。

### 4.2 圆角

| 令牌 | 值 | 用途 |
|---|---|---|
| `radius.xs` | 4 | 徽章、标签、小缩略图 |
| `radius.sm` | 6 | 输入框、次级按钮 |
| `radius.md` | 8 | **卡片、图片、按钮（默认）** |
| `radius.lg` | 12 | 底部面板、抽屉顶部、大图 |
| `radius.full` | 999 | 头像、胶囊标签、圆形图标按钮 |

移动端默认圆角比网站（4–6px）略大，取 8dp，以贴合移动端外观；这是**唯一的主动性视觉偏移**，如需与网站完全一致可整体调回 6dp。

### 4.3 阴影

| 令牌 | 值 | 用途 |
|---|---|---|
| `shadow.none` | — | 默认卡片（用描边而非阴影） |
| `shadow.card` | `0 1 3 rgba(41,78,117,.06)` | 轻浮起卡片 |
| `shadow.overlay` | `0 8 24 rgba(41,78,117,.12)` | 抽屉、菜单、弹层 |
| `shadow.sheet` | `0 -2 16 rgba(41,78,117,.10)` | 底部面板 |

深色模式阴影不可见，**深色下改用 `color.line.strong` 描边表达层级**，不得依赖阴影。

### 4.4 描边

`border.hairline` = 1dp（分割线）；`border.emphasis` = 2dp（选中项、焦点环）。

## 5. 图标与动效

- **图标**：线性风格，24dp 画布、1.5dp 描边、圆头圆角，风格对齐 Lucide / Material Symbols Outlined。底部 Tab 用 24dp，列表内联图标 20dp，徽章内 14dp。
- **禁止**用 emoji 代替功能图标；用户内容中的 emoji 正常渲染。
- **只靠颜色不够**：状态图标必须与文字标签共存（见 §6.5）。
- **动效**：`duration.fast` 120ms（按下态）、`duration.base` 200ms（淡入、展开）、`duration.page` 250ms（页面转场）；曲线统一 `easeOutCubic`。列表下拉刷新与骨架屏不使用弹跳。
- **减少动效**：跟随系统"减弱动态效果"设置，开启时取消位移类动画，仅保留淡入。

## 6. 组件规范

### 6.1 按钮

| 变体 | 浅色 | 深色 | 尺寸 |
|---|---|---|---|
| Primary | 底 `brand.default`，字 `text.inverse` | 底 `brand.solidBg`，字白 | 高 44 / 圆角 `radius.md` / 字 `type.label` |
| Secondary | 底白，边界 `line.button`，字 `brand.default` | 底 `surface.elevated`，边界 `line.strong`，字 `brand.default` | 同 Primary |
| Text | 无底，字 `brand.default` | 字 `brand.default` | 高 44（命中区） |
| Danger | 底 `danger`，字白 | 底 `#8F3A3A`，字白 | 同 Primary |

状态：`default` / `pressed`（primary 换 `brand.hover`，secondary 加 `brand.subtle` 底）/ `disabled`（不透明度 0.55，`cursor: wait` 语义改为禁止点击 + 降低对比）/ `loading`（按钮内 16dp 环形指示器 + 文案保持宽度不变，防跳动）。

### 6.2 输入框

- 静止：底 `field.bg`，边界 1dp `field.border`，圆角 `radius.sm`，内边距 `space.3`×`space.2`，字号 `type.body`（**16sp 起，防 iOS 聚焦缩放**）。
- 聚焦：边界换 `brand.default` + 焦点环 2dp `focus.ring`（offset 2）。
- 错误：边界 `danger` + 下方 `type.caption` 错误文案（颜色 + 文字双表达）。
- 禁用：底 `surface.sunken`，字 `text.muted`。
- 计数器：稿件类字段右下显示 `已输入 / 上限`（标题 200、摘要 500、正文 65535），接近上限（≥90%）转 `warning`。

### 6.3 文章列表项（核心复组件）

```
┌──────────────────────────────────────────┐
│ ┌────────┐  标题最多两行，type.h3        │
│ │ 缩略图 │  摘要最多两行，type.caption   │
│ │ 112×84 │  作者 · 日期 · 阅读量 · 分类  │
│ └────────┘                               │
└──────────────────────────────────────────┘
```

- 无封面时**不留占位图**，标题独占一行（`without-image` 变体），避免每条重复占位图。
- 移动端缩略图缩至 96×72（`radius.xs`）；列表行高 ≥ 56dp，整行可点。
- 命中区覆盖整行，不用"仅标题可点"。
- 元信息用 `type.micro` + `text.muted`；阅读量用数字 + 单位（如 `1.2k` 由 UI 层格式化，不改原始值）。

### 6.4 标签与徽章

- `tag`：胶囊，`radius.full`，底 `brand.subtle`，字 `brand.onSubtle`，`type.micro`，内边距 `space.1`×`space.2`。
- `badge.status`：方角小徽章，`radius.xs`，按 §2.3 取色，`type.micro`，前置于**文字标签**（如 `● 待审核`）。

### 6.5 状态表达（三态必须图文并存）

| 状态 | 图标 | 文案 | 色令牌 |
|---|---|---|---|
| 已发布 | `check-circle` | 已发布 | `status.published` |
| 待审核 | `clock` | 待审核 | `status.pending` |
| 草稿 | `file-pen` | 草稿 | `status.draft` |
| 评论通过 | `check` | 已通过 | `success` |
| 评论发帖被拒 | `alert` | 未通过 | `status.rejected` |

### 6.6 加载 / 空 / 错误

- **骨架屏**：行高 `type.body` 高、圆角 `radius.xs`、底 `color.line.default`（深色 `surface.elevated`），宽度 82% / 45% 交替，不做闪烁动画（用 1.2s 透明度呼吸）。
- **空态**：居中，76dp 圆形底 `brand.subtle` + 图标 + `type.h2` 主文案 + `type.caption` 说明 + 一个 Primary 动作。必须有明确下一步，不留纯文字空白。
- **错误态**：必须区分并列明具体原因，**不得统一显示"加载失败"**（`01-技术方案` §4 硬要求）：网络离线 / 请求超时 / 401 会话过期 / 403 权限不足 / 404 资源不存在 / 429 限流 / 服务器错误 / 业务校验失败，各自文案与动作（重试 / 重新登录 / 返回）。

### 6.7 底部导航（App Shell）

- 4 项固定：首页、分类、搜索、我的。高 56dp + 安全区。图标 24dp + 文字 `type.micro`。
- 选中：图标与文字均为 `brand.default`；未选中：`text.muted`。选中态同时有**字重变化**（400 → 500），不只靠颜色。
- 徽章：未读通知数走 `badge` 红点（`danger`），上限显示 `99+`。
- 二级页（文章详情、登录、编辑器）不替换 Tab 语义；编辑器可隐藏底部导航。

## 7. 布局与断点

| 断点 | 设备 | 行为 |
|---|---|---|
| 320dp | 最窄（SE 一代） | 单列，缩略图隐藏，字号按比例收缩，`space.4`→`space.3` |
| 375dp | 主流小屏 | 单列基准（设计基准之一） |
| 393dp | **设计主基准**（iPhone 15/16 Pro） | 单列，本文所有标注以此为准 |
| 430dp | 大屏手机 | 单列，卡片内边距放宽至 `space.5` |
| ≥600dp | 平板／折叠展开 | 内容最大宽 720dp 居中；列表可双列 |

- 横屏不作为第一阶段核心目标，但**不得因固定宽度崩溃**。
- 长文本、表格、代码块各自横向滚动，页面主体不横向溢出。
- 键盘弹出时底部操作条须上移或可滚动可达，不被遮挡。
