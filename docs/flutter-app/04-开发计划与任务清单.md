# 开发计划与任务清单

## 总体顺序

采用“先证明平台和接口，再做公开阅读，再做会话和会员，最后做投稿/评论深度体验”的顺序。每个阶段完成出口条件后才进入下一阶段；不要先堆页面，再回头重做网络和会话。

## Phase 0：开工前确认

- [ ] 确定 Flutter stable、Dart、Android minSdk、iOS deployment target 和支持设备范围。
- [ ] 确定 APP 工程目录名、包名、Bundle ID、应用名称和图标归属。
- [ ] 确认开发、测试、生产 API origin；创建独立的 Flutter `.env`/配置方案。
- [ ] 用原生 HTTP 客户端验证登录、刷新、退出和 Cookie/token 载体。
- [ ] 用原生 HTTP 客户端验证 Bearer access、body refreshToken、强制旋转、1003 family 失效和新的 refreshToken 持久化。
- [ ] 从 OpenAPI 生成或校验 Dart 模型，记录生成命令和版本。
- [ ] 准备独立测试账号、文章、评论、草稿、图片和通知数据。
- [ ] 确定浅色/深色/跟随系统三套主题 token，并把 HTML 设计稿作为视觉参考。

出口：新工程可以启动空白页面；能登录、刷新、退出；单飞刷新和旋转令牌测试通过；模型生成可重复；测试环境与正式环境不混淆。

## Phase 1：工程骨架与设计系统

- [ ] 创建目录结构、路由、环境配置、日志和错误边界。
- [ ] 建立颜色、字体、间距、圆角、阴影、动效和图标 token。
- [ ] 实现 ThemeMode 跟随系统/浅色/深色和本地持久化。
- [ ] 完成 App Shell、底部导航、顶部栏、加载/空态/错误态、网络状态提示。
- [ ] 建立 widget test 基础和 CI 门禁。
- [ ] 建立 `.github/workflows/flutter-ci.yml`：只读执行 `flutter analyze`、`flutter test`，不在 CI 自动修复代码。

出口：四个底部 Tab 可导航；主题切换不丢页面状态；320dp～大屏手机不横向溢出。

## Phase 2：公开阅读主线

- [ ] 首页焦点、最新、热门、刷新和分页/加载更多。
- [ ] 分类树、标签索引、搜索结果和无结果状态。
- [ ] 文章详情、Markdown、代码块、表格、图片失败、目录和上下篇。
- [ ] 公开会员主页和文章入口。
- [ ] 点赞、收藏、阅读量/阅读历史的匿名与登录分流。

出口：首页→分类/搜索→详情链路可用；正文不会被操作栏遮挡；深色模式下 Markdown 仍可读。

## Phase 3：认证和会员中心

- [ ] 登录、注册、会话恢复、退出和登录后回跳。
- [ ] 并发 401 单飞刷新、退出期间迟到响应丢弃、账号切换隔离。
- [ ] 会员概览、收藏、点赞、历史、资料、密码、通知。
- [ ] 空列表、分页末页、删除失败和权限失败。

出口：冷启动恢复、密码修改使旧会话失效、账号切换无串数据；私有请求不会进入公开缓存；1003/1004/1005/5001 有特定 UX。

## Phase 4：会员投稿

- [ ] 我的文章状态筛选和写文章入口。
- [ ] Markdown 编辑/预览、标题/摘要/分类/标签/封面。
- [ ] 图片选择、粘贴/拖拽能力评估；上传队列、进度、失败重试。
- [ ] 保存草稿、提交审核、撤回、重新送审和删除。
- [ ] 本机恢复、未保存离开保护、上传中保护、冲突提示。
- [ ] 已发布文章修改的影响提示；私人预览不可公开索引。

出口：写稿→保存→刷新→恢复→投稿→审核→发布→修改再送审全链路通过；不会重复创建稿件。

## Phase 5：评论与内容安全

- [ ] 分页评论加载、parentId 组楼、跨页归楼、深层折叠。
- [ ] 回复对象上下文、发布、删除和原评论不可见状态。
- [ ] rejected/reviewing/approved 三态反馈，拒绝后保留输入。
- [ ] 评论列表在暗色模式和动态字体下可读。

出口：20+ 条评论、跨页多级回复、删除父评论、审核隐藏父评论均有明确结果。

## Phase 6：质量、性能与发布准备

- [ ] Android/iOS 真机路径：冷启动、弱网、断网恢复、键盘、返回手势、系统字体。
- [ ] 公开页面、会员页面、投稿和评论的 widget/integration 测试。
- [ ] 包体、首屏、图片缓存、列表 rebuild、Markdown 长文和内存检查。
- [ ] 隐私权限、日志脱敏、HTTPS、证书/域名、商店元数据。
- [ ] 生产环境 API、鉴权、图片、通知和回滚演练。

出口：测试矩阵通过，生产配置和构建签名明确，未把测试账号或本机地址打进发布包。

## 任务优先级

P0：会话、公开文章阅读、主题、投稿状态机、错误恢复、API 安全。

P1：搜索/分类细节、通知、评论展开、图片体验、阅读历史进度、无障碍。

P2：推送通知、离线阅读、分享卡片、动态运营位、动画和个性化推荐。
