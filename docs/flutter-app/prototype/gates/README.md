# M4 原型门禁

第二轮评审 N-2-5 的整改：把原先「只在回复里写了命令、脚本却不在库里」的四道门禁
落成可被第三方复跑的脚本。零第三方依赖（Node 侧只用 Node 22 内置的 `fetch` 与
`WebSocket` 驱动系统 Chrome；Python 侧只用标准库）。

## 一键复跑

```bash
bash docs/flutter-app/prototype/gates/run_all.sh
```

全部通过退出码 0，任一失败非 0。找不到 `node` / `python3` 时脚本会明确报错，
不会静默跳过——**跳过比失败更危险**。

可覆盖的环境变量：

| 变量 | 作用 |
|---|---|
| `NODE_BIN` | 指定 node（默认探测 PATH，其次托管运行时） |
| `PY_BIN` | 指定 python3（默认探测 PATH，其次托管 venv） |
| `CHROME_BIN` | 指定 Chrome/Chromium 可执行文件 |
| `M4_KEEP_SANDBOX=1` | 保留 Chrome 沙箱。**默认关闭**：本机/容器里沙箱初始化失败会连带拖垮网络服务，CDP 端口起不来。仅测试受信任的本地 file:// 页面，风险可接受。 |

## 四道门禁各自查什么

| 脚本 | 断言 | 期望值从哪来 |
|---|---|---|
| `check_routes.mjs` | 每条路由都有渲染内容且未落入兜底；未知路由不白屏且给出出口；本轮零异常 | **从原型源码 `const ROUTES` 抽取**，不手写清单 |
| `check_api_vs_contract.py` | 原型 `api:[...]` 标注没有幽灵端点、方法错、参数名错；方法分隔符统一用逗号 | 从 `docs/api/openapi.v1.yaml` 抽 `paths:` 全量方法 |
| `check_dart_tokens.py` | 四表交叉（字段/构造器/copyWith/lerp）全等；双主题齐备；`dart format` 可解析；06 写明的色值与 Dart 逐值一致 | 从 `app_theme.dart` 与 `06-UI设计规范与设计令牌.md` 各自抽取 |
| `probe.mjs` | 51 条交互断言：点赞/收藏/登录回跳、操作面板无举报、复制失败不谎报、评论删除入口可达性与措辞、被拒反馈条、目录真滚动与缺锚点不谎报、我的文章撤回已清零、编辑器三态按钮矩阵、兜底路由、四态注入、搜索命中与空态、分类展开、通知已读、主题切换、运行时零错误 | 真点击驱动 + 读 DOM/`scrollTop`，不读自陈 |

## 设计约定（踩过的坑，别再踩）

1. **期望值能程序化推导就绝不手写。** 路由表、字段表、端点表一律从被测对象自身抽取。
   手写清单最坏的结果不是报错，而是**把「清单写错」伪装成「测试通过」**——
   第一轮就发生过：手写路由清单虚高为 21/21，其中 2 条路由根本不存在。
2. **测真行为，不测提示文案。** 目录跳转要看 `scrollTop` 有没有变，不能只看
   toast 说了什么；复制链接要看失败时报的是不是失败。
3. **断言「某文本已消失」必须先排除 `<script>` 源码。** `<script>` 就在 `<body>` 里，
   用 `body.textContent` 断言会恒为真。
4. **`grep` 的或运算一律用 `-E`。** macOS 是 BSD grep，`"a\|b"` 不是或运算而是字面量，
   会给出假阴性（本轮排查 N-2-3 时就踩到过）。
5. **本阶段 Dart 侧只有 `dart format --output=none` 可用。** 没有 `pubspec.yaml` 时
   `dart analyze` 会报几百条未解析符号，那是环境缺失，不是文件缺陷——别被 374 条吓到。
