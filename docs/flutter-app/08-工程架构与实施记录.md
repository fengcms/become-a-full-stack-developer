# Flutter APP 工程架构与实施记录

2026-10-02。用户授权自主裁决并进入实际开发。

## 工程决策

- 工程：`flutter-app`，包名 `com.yingzhou.fullstack_reader`，应用名“成为全栈”。Flutter 3.47.1 / Dart 3.13.1；Android 为本机验收平台，iOS 工程同时保留。
- Riverpod 注入 API、会话与主题；go_router 管理四个主入口和私有路径回跳；Dio 统一处理信封、错误、超时与单飞刷新。表单输入保留在页面，服务端内容经模型适配后显示。
- access token 仅内存，refresh token 安全存储；退出与切换账号递增会话代次，丢弃旧响应。私有页面以会话代次重建，不持久化私有接口缓存。
- Markdown 使用 flutter_markdown_plus/GFM。服务端目录为唯一数据源，按渲染标题的层级与文本顺序核验匹配；不能匹配的条目不跳到错误标题。正文 Widget 使用服务端 anchor 建立 key，不自行 slug 化。
- 投稿显式创建 draft/pending，更新不传 status；编辑器保存本机恢复副本，按账号与稿件隔离；离开保护、上传状态、失败保留输入和服务端状态冲突检查必须实现。
- `tool` 保存契约模型生成器、本地后端准备脚本和联调脚本；生成文件可重建，依赖锁定在 pubspec.lock。
- API 通过 `--dart-define=API_BASE_URL=...` 配置。开发使用独立 SQLite（`flutter-app/.local`）和 11002 端口，Android 模拟器访问宿主 `10.0.2.2`；不写生产环境。

## 自主裁决的设计差异

07 §12 的 D1–D13 按用户本轮授权处理：导航图标 24dp、文字 11sp、选中 600；徽章图标 14dp；次级按钮用 lineButton；列表正文 15sp；深色输入框用 surfaceElevated；焦点使用原生 2dp 边框；引文 1.7 行高；骨架沿用 AppColors.skeleton；info 使用 brandOnSubtle/brandSubtle 语义；浅色 elevated 等于 surface；危险操作保留二次确认；所有异步按钮有 loading/disabled；页面筛选与调试控件分开。无需再次请求确认。
