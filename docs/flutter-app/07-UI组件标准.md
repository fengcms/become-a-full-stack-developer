## 2. 通用约定

### 2.1 状态命名统一用这五个词

所有组件的状态名收敛到同一套词汇，避免出现 `active` / `on` / `checked` / `selected` 四种说法：

| 状态 | 含义 | 通用表达 |
|---|---|---|
| `default` | 静止 | — |
| `pressed` | 按下／点击反馈 | 背景变 `color.brand.subtle` 或 `color.brand.hover` |
| `focused` | 键盘／输入焦点 | 边界换 `color.brand.default` + 焦点环 |
| `disabled` | 不可用 | 不透明度 0.55 + 禁止点击 |
| `loading` | 进行中 | 组件内指示器，**并保持原宽度不变**（防跳动） |
| `selected` | 选中（可重复状态） | 见 §5 各组件 |

> 原型内部用 `.on` 作为 class 名（HTML 习惯），Flutter 侧字段/枚举一律用 `selected`。改名不改形。

### 2.2 命中区下限 44×44dp

`AppSpacing.minTapTarget = 44`。**视觉尺寸可以更小，命中区不行。**

这条最容易被违反的地方是行内小控件：单选的视觉圆是 22dp，但它的命中区由所在的 `.cell`（`min-height: 52px`）承担。开发时**不要把命中区缩到视觉尺寸上**。

### 2.3 尺寸口径：视觉尺寸 vs 布局尺寸

本文每个组件都给出两类数字，别混用：

- **视觉尺寸**：图标、圆点、指示器 —— 决定"看起来多大"
- **布局尺寸**：行高、内边距、外边距 —— 决定"占多大地方"

例：`.cell` 的行高是 52dp（布局），里面的图标区是 22dp 宽、图标本体 20dp（视觉）。

### 2.4 圆角与间距一律取令牌，不写字面量

- 圆角：`radius.xs / sm / md / lg / full`（`AppRadius`）
- 间距：`space.1 ~ space.10`（`AppSpacing`）
- 动效时长：`duration.fast(120) / base(200) / page(250)`（`AppDuration`），曲线统一 `easeOutCubic`

### 2.5 图标尺寸的落地方式（重要，容易踩坑）

原型里图标是 SVG sprite，`.i` 统一 `width:1em;height:1em`，**尺寸靠 `font-size` 控制**。所以看到 `.cell .ci{font-size:20px}` 应理解为"图标 20dp"。

`06 §5` 规定的三档：

| 场景 | 尺寸 | 原型写法 |
|---|---|---|
| 底部 Tab | 24 | `.tabbar button svg.i{font-size:…}` ⚠️ 见 §12-D1 |
| 列表内联 | 20 | `.cell .ci{font-size:20px}`、`.entry` 内联 |
| 徽章内 | 14 | `.badge-dot` / `.chip svg.i{font-size:12px}` ⚠️ 见 §12-D2 |

Flutter 侧不要引外部图标包：`app_theme.dart` 的 `ArticleStatusView` / `ApiErrorView` 用 `IconData`（`Icons.*`）保证 tree-shaking。

## 3. 按钮

### 3.1 通用尺寸与状态

| 项 | 值 | 令牌 / 来源 |
|---|---|---|
| 最小高度 | 44 | `AppSpacing.minTapTarget`（`06 §6.1`） |
| 圆角 | 8 | `radius.md` |
| 内边距（横向） | 20 | `space.5` |
| 字 | 14 / 500 | `type.label` |
| 图标与文字间隙 | 6 | 原型实测（`gap:6px`） |
| 图标尺寸 | 17 | 原型实测 |

状态矩阵（**四变体共用，不要各写一套**）：

| 状态 | Primary | Secondary | Text | Danger |
|---|---|---|---|---|
| `default` | 底 `color.brand.solidBg`，字 `color.text.inverse` | 底 `color.surface.default`，边界 `color.line.button`，字 `color.brand.default` | 无底，字 `color.brand.default` | 底 `color.danger`，字 `color.text.inverse` |
| `pressed` | 底 `color.brand.hover` | 底 `color.brand.subtle` | 底 `color.brand.subtle` | 底 `color.danger`（不加深） |
| `disabled` | 四个变体一致：不透明度 0.55，禁止点击 | | | |
| `loading` | 组件内 16dp 环形指示器；**文字保留原宽度**，只用 `Visibility` 藏字，不 `if` 掉整段 Text | | | |

### 3.2 Primary 主按钮

- 用于：页面唯一的主行动（登录、提交投稿、保存）
- **一屏内最多一个**。出现两个时，把次要动作用 Secondary 或 Text。
- 宽度：表单底部用 full width（`.b.wide`）；行内并排时按内容宽。
- 落地：`filledButtonTheme`（`app_theme.dart` 已装配 `backgroundColor: brandSolid`、`minimumSize: (0, 44)`、`padding: horizontal s5`）。**直接 `FilledButton` 即可，不要再包一层自定义样式。**

### 3.3 Secondary 次级按钮

- 用于：主行动之外的并列选择（取消、返回、重置）
- 边界用 `color.line.button`（**不是** `color.line.strong`）。这两个令牌差别很细但语义不同：`line.strong` 是"容器需要更明确的边界"，`line.button` 专供次级按钮。
- 落地：`outlinedButtonTheme` 已装配。注意 `app_theme.dart` 当前用 `lineStrong` 画边界，与本文口径不同 —— 见 §12-D3。

### 3.4 Danger 危险按钮

- 用于：不可逆操作（删除文章、永久删除评论、注销账号）
- **删除类操作优先用 Cell 形态**（`.cell.danger` + 底部面板二次确认），而不是一屏一个红色大按钮。危险按钮适合放在确认弹层的动作位。
- **当前原型无消费方**（危险语义走 `.cell.danger`），样式按"规范完整"保留。首个消费方出现时不要改样式，直接用。

### 3.5 Text 文字按钮

- 用于：轻量动作、行内补充操作（分组的「更多」、表单的「忘记密码」）
- 高度仍须 44（命中区），但**视觉上不画底**。所以它看起来矮、点起来高 —— 这是刻意的。

### 3.6 IconButton 图标按钮

| 项 | 值 |
|---|---|
| 命中区 | 44×44 |
| 圆角 | `radius.full` |
| 图标 | 20 |
| `pressed` | 底 `color.brand.subtle` |
| 贴边 | 顶栏首尾用负外边距（原型 `.iconbtn.edge` = -10px）抵消内边距，让图标光学对齐 |

- 必须有 `aria-label` / `tooltip`。纯图标按钮没有文字，读屏的用户只能靠它。
- 顶栏图标按钮与 Cell 图标按钮**不是同一个组件**：前者 44dp 命中且圆形，后者是行的一部分（见 §4.2）。

## 4. 列表与 Cell

移动端信息架构的主力形态。**能用列表就不用卡片网格**——网格磁贴在窄屏上会挤掉文字可读性。

### 4.1 CellGroup 分组容器

| 项 | 值 | 令牌 |
|---|---|---|
| 外边距（横向） | 16 | `space.4`（页面左右边距） |
| 底 | `color.surface.default` | |
| 边界 | 1dp `color.line.default` | `border.hairline` |
| 圆角 | 8 | `radius.md` |
| 溢出 | `hidden`（让首末项的直角被圆角裁掉） | |
| 分组之间垂直间距 | 12 | `space.3` |

- 一个分组只放**同一语义类别**的项。外观归外观、账号归账号。
- 分组之间用 `.sec-head`（§7.5）加小标题，不要用大标题。

### 4.2 Cell 单项

| 项 | 值 | 令牌 |
|---|---|---|
| 最小高度 | 52 | 原型实测（≥ `space.10`+`space.3`） |
| 内边距 | 纵向 10 / 横向 16 | 横向 `space.4` |
| 结构 | 图标槽 → 文本区（弹性） → 尾部（值／角标／箭头） | |
| 图标槽宽 | 22（图标本体 20） | 见 §2.5 |
| 图标色 | `color.brand.default`；次要项 `color.text.muted` | |
| 主文字 | 14.5 / 400 / `color.text.body` | 见 §12-D4 |
| 副文字 | 11.5 / `color.text.muted`，上间距 3 | |
| 尾值 | 13 / `color.text.muted` | |
| 箭头 | 15 / `color.text.muted` | |
| 分隔线 | 1dp `color.line.default`，**最后一项不画** | |
| `pressed` | 底 `color.bg.subtle` | |

排布要点：

- 文本区必须 `min-width: 0`，否则长标题会把尾部箭头挤出容器。
- 一行标题用 `strong`，副标题用 `small`。两行时不要都给 600 字重。
- 可点用 `<button>` / `InkWell`；纯展示用 `plain`（不响应按压、不画 hover）。

### 4.3 Cell 变体

| 变体 | 选择器 | 形态 |
|---|---|---|
| 跳转项 | `.cell` + `data-nav` | 尾部箭头 |
| 展示值 | `.cell` | 尾部 `.cv` 文字，无箭头 |
| 带角标 | `.cell .cd` | 尾部红底圆角胶囊，最小宽 18、高 18、内边距 0 5、字 10/600 |
| 危险项 | `.cell.danger` | 图标与主文字换 `color.danger`；**不改底色** |
| 只读项 | `.cell.plain` | 无箭头、无按压反馈 |

- 角标上限显示 `99+`（`06 §6.7`）。角标是"计数"不是"状态"，别拿它当状态徽章用。
- 危险项**不要**做成红底。一屏一个红底块已经足够刺眼，且会破坏分组的一致性。

### 4.4 文章列表项 Entry

```
┌────────────────────────────────────────────┐
│ ┌────────┐  标题（≤2 行，16/1.5/600）        │
│ │ 缩略图 │  摘要（≤2 行，12.5/1.65/muted）   │
│ │ 96×72  │  作者 · 日期 · 阅读量 · 分类      │
│ └────────┘                                 │
└────────────────────────────────────────────┘
```

| 项 | 值 | 令牌 |
|---|---|---|
| 内边距 | 16 | `space.4` |
| 缩略图 | 96×72，圆角 4 | `radius.xs` |
| 缩略图与文字间距 | 12 | `space.3` |
| 元信息 | 11 / `color.text.muted`，间隔 8 | `type.micro` |
| 元信息分隔点 | 2×2 圆点，与文字同色、不透明度 0.6 | |
| 行高 | ≥56（`06 §6.3`） | |

- **无封面不留占位图**：`.entry.noimg` 直接隐藏缩略图，标题独占整行。给每条都画一个灰块是最常见的偷懒。
- 整行可点，不是只有标题可点。
- 阅读量格式化（`1.2k`）归 UI 层，**不改原始数值**。原始值要留给排序与接口。

### 4.5 通知项 Notice

| 项 | 值 |
|---|---|
| 内边距 | 16 / `space.4` |
| 图标底 | 36×36，圆角 `radius.md`，底 `color.surface.default`，边界 1dp `color.line.default` |
| 未读底 | `color.brand.subtle` |
| 未读点 | 6×6 圆点，`color.danger`，置于标题行内 |
| 标题 | 14 / 600 / `color.text.title` |

- 「未读」同时有**底色**和**圆点**两种表达，不是只靠底色。
- 「全部已读」后未读数必须归零，且要有 Toast 反馈（`gates/probe.mjs` 已在测这条）。

## 5. 选择类控件

### 5.1 Radio 单选

| 项 | 值 |
|---|---|
| 视觉尺寸 | 22×22 |
| 边界 | 2dp `color.line.strong`；选中换 `color.brand.default` |
| 选中指示 | 居中圆点 10×10，`color.brand.default` |
| 未选中指示 | 同尺寸圆点，`scale(0)`（**占位但不可见**，避免选中时布局跳动） |
| 动效 | `duration.fast`，只做 `transform: scale` |
| 命中区 | 由所在 Cell 承担（§2.2） |
| 落地 | `Radio` + `RadioGroup`；**不要**把 `Radio` 塞进 `Row` 再手写间距，用 Cell 结构包 |

⚠️ **单一指示器铁律**：一个单选圆里**只能有一个**视觉指示（圆点）。

原型本轮修过一个真实缺陷：`.radio` 是 `display:grid`，里面同时放了勾选图标和 `::after` 圆点，Grid 把两个子项排成**两行** → 内容总高 24.5dp 溢出 22dp 圆框 → 渲染出"勾戳出圆外、圆点吊在圆下"的破图形。详见 §11-A2。

Flutter 侧同理：`Radio` 的 `fillColor` 与 `side` 已经负责指示，不要再叠一个 `Icon(Icons.check)`。

### 5.2 Checkbox 多选

**当前原型无消费方**（页面地图里没有多选场景）。形态按下列口径，首个消费方出现时直接用：

| 项 | 值 |
|---|---|
| 视觉尺寸 | 22×22 |
| 圆角 | 6（`radius.sm`）—— **方角**，与单选的圆角形成可辨识差异 |
| 未选中 | 边界 2dp `color.line.strong`，无底 |
| 选中 | 底 `color.brand.default`，边界同色，勾图标 `color.text.inverse`，尺寸 14 |
| 命中区 | 由所在 Cell 承担 |
| 落地 | `Checkbox`；`CheckboxListTile` 可，但须核对内边距落回 §4.2 口径 |

- 单选 → 圆 + 圆点；多选 → 方 + 勾。**形态差异必须存在**，只靠"能不能多选"的行为差异，用户看不出来。
- 需要一个「全选」时，它是普通 Checkbox，不加特殊样式。

### 5.3 Switch 开关

**当前原型无消费方**（推送类属 Non-goal，见 `02-页面地图与交互规格`）。形态按下列口径：

| 项 | 值 |
|---|---|
| 轨道 | 44×26，圆角 `radius.full` |
| 滑块 | 22×22 圆，底 `color.surface.default`，右侧内边距 2 |
| 关 | 轨道 `color.line.strong` |
| 开 | 轨道 `color.brand.default` |
| 落地 | `Switch` + `SwitchListTile`（`adaptive: true` 以贴合平台） |

- 开关**立即生效**，不配"保存"按钮。需要保存的用 Checkbox。
- 切换后必须有可撤销的反馈（Toast 提供撤销入口）。误触是开关类控件的主要投诉来源。
- 末位文案说清后果（"开启后每天收到一次摘要"），不要只写"接收通知"。

### 5.4 Segmented 分段控件

原型里有两处同名不同物的东西，**别混用**：

| 用途 | 选择器 | 形态 |
|---|---|---|
| 页面内筛选（如会员中心的"全部/待审核/已发布"） | `.segs` | 胶囊按钮横排，可横向滚动 |
| 编辑器工具栏／外壳调试开关 | `.seg` | 方角小按钮组，`aria-pressed` |

页面内筛选取 `.segs`：

| 项 | 值 |
|---|---|
| 高 | 32 |
| 圆角 | `radius.full` |
| 字 | 12.5 / 500 |
| 未选中 | 底 `color.surface.default`，边界 1dp `color.line.default`，字 `color.text.muted` |
| 选中 | 底 `color.brand.subtle`，边界同色，**字 `color.brand.onSubtle`**，字重 600 |

⚠️ 选中字色必须用 `color.brand.onSubtle`。用 `color.brand.default` 在 `color.brand.subtle` 底上只有 4.29:1，不达标（`06 §2.5` 已列此例外）。
⚠️ 选中态**同时**有底色、边界色、字重三种变化，不只靠颜色。

- 项数 ≤5 且文字短时用分段；否则用横向标签流（`.segs` 溢出即可滚动，但 8 项以上用户找不到）。
- 分段控件**不做**嵌套。

## 8. 加载 / 空 / 错误

### 8.1 骨架屏 Skeleton

| 项 | 值 |

| 文本行高 | 14（`type.body` 高），圆角 `radius.xs` |
| 缩略图块 | 96×72，圆角 `radius.xs` |

### 8.2 空态 / 错误态 EmptyState

| 项 | 值 |
|---|---|
| 容器 | 纵向内边距 64，横向 `space.6`，居中 |
| 圆底 | 76×76，圆角 `radius.full`，底 `color.brand.subtle`，图标 30 |

|---|---|---|
| `offline` | 网络不可用 | 重试 |
