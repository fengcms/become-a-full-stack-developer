# 文章详情交互修复（2026-10-02）

本次仅修改 Flutter APP，未修改后端或网站项目。

## 问题与处理

1. 点赞、收藏采用乐观更新：点击立即更新选中状态，点赞数立即增减；请求失败恢复之前状态并提示。两项独立锁定正在进行的请求，避免重复发送，并允许同时操作另一项。点赞成功使用接口响应的 `liked`、`likeCount` 校准，不再等待收藏列表扫描。
2. 文章互动区对照原型 `.actions`，顶部、底部分隔线内各留 20px，按钮之间 12px，窄屏换行也保留间距。
3. 顶部作者信息使用首次加载的 `a.data.likeCount`，是 APP 显示旧数字的原因。现在顶部与底部共用动态计数，首次从文章初始化，随后由状态接口、乐观更新和写入响应维护。
4. Markdown 围栏代码读取语言标记，使用 highlight 语法解析生成可选择文本；语言标签和复制按钮置于代码栏。关键词、字符串、数字等适配深浅主题；未知语言及未标记代码保留原文，未标记显示“纯文本”。复制保留原始代码。
5. 评论输入框显式处理触摸外部失焦，页面拖动也关闭键盘。
6. 评论按原型改为左侧主评论头像、右侧内容列；回复置于内容列内，浅色背景、12px 内边距、6px 圆角，显示回复对象、两行原文引用、回复内容及操作。跨页归楼、缺失父评论、展开/收起逻辑保留。
7. 评论列表与输入区之间保留 24px。
