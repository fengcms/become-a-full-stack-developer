## 第一批互斥边界

- M2-01 只讲工程约束，不提前展开路由或业务组件。
- M2-02 只讲布局、路由和入口边界，不展开 token 刷新细节。
- M2-03 讲请求协议与并发恢复；token 存储方案留给 M2-07。
- M2-04 讲契约类型流；请求运行机制回链 M2-03，不重复实现。

第一批全部使用当前提交 `2b54f1e` 之后的工作树作为素材。正式创建 `react-frontend-v1.0` 后，再统一把文章辅助区的里程碑从“待创建”改为真实 tag。
