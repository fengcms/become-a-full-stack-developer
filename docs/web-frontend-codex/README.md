# 前台重做：决策与协作素材

记录日期：2026-09-22。

这组文档整理本次 `web-frontend-codex` 开发中可复核的工程决策、依据、取舍和复盘，不是逐字的内部推理日志。依据来自用户已确认的需求、实际实现、工具检查和浏览器验证。事后提出的维护建议单独标明，不把它们写成当时已经实施的功能。

建议阅读顺序：

1. [产品与设计决策](01-产品与设计决策.md)：哪些要求必须保留，哪些细节可以自主决定，设计与真实数据如何协调。
2. [工程决策与取舍](02-工程决策与取舍.md)：复用边界、会话、代理、缓存、Markdown、测试环境与部署边界。
3. [问题复盘与验证证据](03-问题复盘与验证证据.md)：实际失败过的地方、为何原有检查没有发现、怎样修复和验证。
4. [后续协作与维护备忘](04-后续协作与维护备忘.md)：不能轻易删除的处理、已知规模限制、下一位协作者如何接手。
