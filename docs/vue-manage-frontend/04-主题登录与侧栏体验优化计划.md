# Vue 后台主题、登录与侧栏体验优化计划

| 项 | 内容 |
|---|---|
| 状态 | 已确认，实施中 |
| 日期 | 2026-10-09 |
| 范围 | `manage-frontend-vue/` 的主题、全局配色、登录页和导航壳 |
| 对照 | `manage-frontend/` React 管理后台 |
| 契约影响 | 无；不改后端、API 或登录业务规则 |

## 1. 目标

修复 Vue 管理后台相对 React 版本的四项体验差距：缺少明暗模式、登录页信息和视觉层次不足、侧栏没有手动收起入口、全局配色没有沿用 React 后台的设计令牌。

React 版的主题基线在 `manage-frontend/src/index.css`：默认跟随系统，提供 light/dark 两套颜色令牌，主色为偏蓝紫的 indigo；浅色侧栏使用浅中性色，深色侧栏使用深色背景。React 的 `ThemeProvider` 使用 `theme` 作为本地存储键，顶栏提供明暗切换；侧栏折叠状态保存在 `befull-admin-ui`。Vue 当前主要颜色和侧栏颜色是固定值，登录页则是单卡片居中布局。

## 2. 实施顺序

### 功能一：主题系统与 React 配色对齐

- 建立 Vue 主题状态：`light`、`dark`、`system`；初始跟随系统，手动切换后持久化。
- 使用与 React `next-themes` 相同的 `theme` localStorage 键，便于同一浏览器内两版后台保持主题选择一致。
- 在应用入口前恢复主题 class，避免首屏闪烁；系统偏好变化时，仅在 `system` 模式下自动响应。
- 将 Vue 全局页面、侧栏、顶栏、卡片、文字、边框、焦点环和语义状态颜色改为 CSS 主题令牌，浅/深两套令牌参考 React 版。
- 将 Naive UI `NConfigProvider` 切换到匹配的 light/dark theme，并提供顶栏明确的明暗切换按钮。
- 检查文章 Markdown 编辑器和组件库弹层，使其随主题正确切换。

### 功能二：登录页重做

- 沿用 React 版左品牌介绍、右登录表单的两栏构图，展示站点名称、简介、后台能力说明和版权信息。
- 登录表单继续使用现有用户名/密码接口、校验、角色分流、回跳和错误提示。
- 不添加注册、第三方登录或记住密码等 API 不支持的能力。
- 窄屏改为单栏表单，并保留品牌标识；登录页也使用统一主题令牌。

### 功能三：可折叠侧栏和移动导航

- 顶栏加入桌面侧栏切换按钮；展开宽度约 244px，折叠宽度约 68px，仅展示图标。
- 折叠状态存入与 React 一致的 `befull-admin-ui`，读取其 `sidebarCollapsed` 字段。
- 折叠项提供 tooltip/title 和可访问名称，保留选中状态与导航能力。
- 与 React 对齐响应式断点：常规桌面可展开/折叠，中等宽度默认采用窄侧栏，小屏使用遮罩抽屉和菜单按钮，点击导航后关闭。
- 将个人中心页面也纳入统一后台壳，避免只有管理页面支持侧栏状态。

## 3. 验收标准

- 手动切换明暗后刷新，选择保持；选择 `system` 时能跟随操作系统颜色偏好。
- 浅色侧栏、主色、卡片和背景与 React 浅色后台一致；深色下页面主体、Naive UI 组件、通知/弹窗、编辑器均无白底漏网或低对比文本。
- 登录页在桌面有清晰的品牌区与表单区，在 320px 窄屏可完整使用；登录和错误流程保持原行为。
- 桌面侧栏按钮能展开/折叠并在刷新后恢复；折叠态只显示图标且每项可辨认、可键盘访问。
- 小屏菜单能打开、关闭、遮罩关闭，并在导航后自动收起；页面主体宽度和滚动不被侧栏遮挡。
- `pnpm check`、`pnpm typecheck`、`pnpm test`、`pnpm build` 全部通过。
- 在当前本地运行页面检查登录、浅/深主题、文章列表、编辑器、弹窗和至少一个窄屏尺寸。

## 4. 提交边界

按每项已完成的功能分别提交：

1. `docs(vue-admin): 规划主题登录与导航体验优化`
2. `feat(vue-admin): 对齐 React 后台主题并支持明暗模式`
3. `feat(vue-admin): 重做品牌化登录页面`
4. `feat(vue-admin): 支持侧栏折叠与移动导航`

若某项实现中发现必须拆分的修复，也以独立 Conventional Commit 提交。每个功能提交前运行相应检查；最后一项完成后再运行全套质量门禁。
