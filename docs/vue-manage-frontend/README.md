## 当前决策

采用 Vue 3 + Vite + Naive UI + TypeScript，依赖与运行时版本由 `manage-frontend-vue/pnpm-lock.yaml` 和 `package.json` 固定。格式化与 lint 使用 Biome。文章编辑器已通过页面集成方式确定为 `md-editor-v3`，带认证图片上传适配；实现细节和验证边界见实施记录。
