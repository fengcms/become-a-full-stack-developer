## 可复跑

在 node-backend 目录：

```sh
pnpm typecheck
pnpm test
pnpm exec tsx scripts/verify-wechat-d1.ts
DB_FILE=./data/app.db pnpm exec tsx scripts/migrate-wechat-local.ts
```

D1 验证脚本复用仓库 web-frontend 中 Wrangler 的 Miniflare 5（使用 convertV4MiniflareOptions），需该工程已安装依赖。它创建临时测试 D1，不连接线上。

本地迁移可重复执行，已存在字段则跳过。正式 D1 增量 SQL 由 Wrangler migration journal 管理，只应用 0001，不重放 0000，不重建 users 表。

首次设置使用条件 UPDATE 和同一原子批次中的 changes() 门控撤销。用户名冲突导致整个批次回滚；条件更新 0 行时，不撤销另一请求成功后签发的令牌。新 AuthResult 在提交后签发；响应丢失可通过新密码或微信登录恢复。数据库迁移是内部扩展，不改变既有密码登录协议。
