## 已上线能力

- `POST /api/v1/auth/wechat/callback`：单个小程序的 code 验证、首次建号、重复登录复用用户。

- `POST /api/v1/me/setup-account`：设置用户名密码，保持 userId 与业务归属，撤销旧刷新令牌并返回新 AuthResult。既有网站、APP 继续密码登录。

## 后续配置与复核

在 node-backend 目录通过 Wrangler 的交互式 Secret 输入配置，不将值写入 Git、命令参数或聊天记录：

```sh
wrangler secret put WECHAT_MINI_APP_ID
wrangler secret put WECHAT_MINI_APP_SECRET
```

后续小程序开发时使用匹配 AppID 的 wx.login code，验证首次登录、重复登录、设置用户名密码、网站/APP 登录同一账号。在开发工具关闭域名校验；上线备案等不纳入本轮。具体接入说明见小程序账号文档。

`node-backend/scripts/smoke-wechat-remote.mjs` 是本次缺配置阶段的烟测脚本：默认只读；显式 ALLOW_REMOTE_WRITE=1 才创建并清理测试用户。它断言缺配置响应，因此配置微信密钥后不应原样作为真实微信验收脚本运行。脚本输出不含凭据。线上数据库备份保留在 Git 忽略的 .wrangler/backups。
