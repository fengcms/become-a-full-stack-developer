## 二、P2-1 整改证据

**契约机器字段**（`openapi.v1.yaml` `SiteSettingUpdate.logoUrl`）：`{type: string, nullable: true, maxLength: 512}` → 允许 `null` 清空。

**代码修复**（`src/routes/site.ts:54`）：
```diff
-  logoUrl: z.string().max(512).optional(),
+  logoUrl: z.string().max(512).nullable().optional(),
```
下游 `if (patch.logoUrl !== undefined) set.logoUrl = patch.logoUrl;` 对显式 `null` 为 `true` → `set.logoUrl = null` → DB 清空，行为正确。

**回归测试**（`test/routes/aux.test.ts` PATCH 段，并入既有用例）：
- 先 `PATCH { logoUrl: 'https://example.com/logo.png' }` → 断言返回 `logoUrl` 为该值；
- 再 `PATCH { logoUrl: null }` → 断言返回 `logoUrl` 为 `null`（清空路径覆盖）。

修复前该路径会触发 zod `.optional()` 拒收 `null` → 4001；修复后走清空逻辑。NOTES §二.7「`null` 显式清空（如 `siteTitle`、`logoUrl`）」现已与代码一致（此前为自陈矛盾）。
