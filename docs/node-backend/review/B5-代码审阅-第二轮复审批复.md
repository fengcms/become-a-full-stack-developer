### P3-4 ✅ 用户管理锁定保护（users.ts:77-103）
- ① 自我护栏：当 `privileged`（含 role/status 变更）且 `Number(c.get('user').id) === id` → `403 FORBIDDEN`（code 2001）。防自我降级/封禁锁死。
- ② 最后 admin 保护：当 `privileged` 且 `existing.role==='admin'` 且（将失 admin 或遭 disabled）且活跃 admin 计数 `≤1` → `409 CONFLICT`（code 3002）「至少保留一名活跃 admin」。
- 纯 `level` 变更（:77 `privileged` 仅当 role/status 有值）→ 两道护栏均不触发，符合「level 仅展示」意图。
- 错误码 `2001`(FORBIDDEN)/`3002`(CONFLICT) 均为契约既有值，无新增 ErrCode。
- **逻辑真修，非登记。**

### P3-5 ✅ SVG XSS 缓解（files.ts:45-47）
- 直出路径对 `image/svg+xml` 强制 `Content-Disposition: attachment`，统一加 `X-Content-Type-Options: nosniff`；非 svg 用 `inline`。
- 本地预览路径下 SVG 不再被浏览器内联渲染，XSS 面关闭。

## 四、非阻塞观察（不阻放行，供参考）
