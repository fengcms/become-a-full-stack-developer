## 四、回复"超出范围的 2 真实缺陷"核验（均真修复、方向正确）

开发 AI 借新增的契约一致性测试，主动揪出并修复了 2 个此前人工审阅与双门禁都漏掉的缺陷。我独立核验**两处均真修复，且方向相反恰好印证"契约一致性需机器校验"**：

1. **契约自身缺陷（改契约）**：`POST /auth/{provider}/callback` 原 `501` 响应 `example.code` 误写 `5000`（与 501 自相矛盾且契约无 501 码）。
   - **核验**：契约该响应现为 `responses: ['429','200','500']`，`example.code=5000`，与 `code 5000 ↔ 500` 自洽；全文残留 `501` 仅 1 处（`openapi.v1.yaml:984` 为 §3.1 扩展端点说明文字，非 HTTP 状态声明）。
   - **判定**：✅ 真修复，方向正确。

2. **本方代码缺陷（改代码）**：`ACCOUNT_DISABLED`(1005) 原误映射为 `403`。
   - **核验**：`codes.ts:57` 已改 `ACCOUNT_DISABLED: 401`；且契约 `POST /auth/login` 与 `POST /auth/refresh` 的 **401** 响应 `example.code` 确为 **1005**（"账号禁用返回 401/code 1005，不返回 403 避免暴露账号存在性"）——代码改 401 **与契约一致、方向正确**。
   - **判定**：✅ 真修复，方向正确。

> 关键价值：新增 `test/contract/error-codes.test.ts` **真解析 yaml**，遍历每个响应的 `code→HTTP` 断言与 `HttpForCode` 一致（it#1），并断言每个 `BizErrorCode` 在契约有声明（it#2）。这把 B01 类回归前移到测试，且**实测能抓到上述两缺陷**——比第一轮 B07"自陈核查表"质级跃升。

## 五、本轮新引入缺陷排查（无高危 / 中危）

针对最易"修 A 坏 B"的三处（双部署 / 路径净化 / CORS），专项排查：

- **双部署**：`worker.ts` 由 `createApp(appEnv)` 在请求作用域构造，`app.ts` 不再顶层求值 `process.env`；CF 导入 `app.ts` 不会崩溃。✅
- **路径净化**：`resolveKey` 拒绝 `../` 等非法字符，杜绝 `join(root, key)` 越权逃逸。✅
- **CORS**：开发 `*`+无凭据合法；生产白名单 + 凭据；`*`/空拒绝跨域。根除 `*`+credentials 反模式。✅
- **错误信封**：`error.ts` 仍为 `code/message/data/requestId` 四字段，与契约 `ApiResponse` 一致，兜底 5000。✅
- **`@/` 别名**：grep `../` 于 `src/`、`test/` 仅命中 2 处且**均非 import 引用**（注释示例 + 测试内 `import.meta.url` 定位契约），所有模块 import 已 `@/` 化。✅

## 六、非阻塞观察清单（低危，不阻 B1）

以下为独立发现的改进点，均**不构成不通过**，供 B1 及后续批次顺手处理：

1. **【低危】`wrangler.toml` 缺 `compatibility_flags = ["nodejs_compat"]`**：当前 B0 不触发（worker 入口不导入 `node:fs`）。但 B5 一旦接线 `storage.ts`（其 `import node:fs/promises`、`node:path`、`node:crypto`），CF 部署将暴露构建/运行时错误。建议 B5 前补 `compatibility_flags`。
2. **【极低危】`worker.ts` 每次请求重建 `createApp` + `createD1Db`**：轻微重建开销，B0 阶段装配轻量可接受；若后续装配变重，可提升到模块级缓存（注意 D1 绑定与请求绑定不同）。
3. **【低危】`error-codes.test.ts:45` 用 `URL('../../../docs/api/openapi.v1.yaml', import.meta.url)` 相对定位**：依赖 test 目录深度（3 层），跨出 `src` 指向项目级契约；若测试目录结构调整会断。可改为基于仓库根的绝对解析或配置化路径。
4. **【提示】`app.ts:32` `protected-ping` 占位路由**：B1 起将被真实鉴权端点替换，属预期占位。
