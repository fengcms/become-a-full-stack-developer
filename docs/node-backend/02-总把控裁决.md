## 🟠 P1 — 已裁定

### Q3 · 刷新令牌：采用有状态 `refresh_tokens` 表（选项 A）
- **裁定**：选 **A**（契约保真是核心卖点）。无状态 JWT 无法实现 02 §九 P11 要求的"刷新旋转 + 登出作废"。
- **做法**：建 `refresh_tokens` 表（`token_hash`, `user_id`, `expires_at`, `revoked_at` 默认 null）。`login`/`refresh` 签发并入库；`refresh` 时校验未吊销且未过期 → 签发新令牌并置位旧 `revoked_at`（旋转）；`logout` 置位当前 `revoked_at`（作废闭环）。
- **已落地**：`01-auth.md` 端点清单 + 行为指引已改（不再"从简无状态"）。

### Q4 · 用户表命名：统一 `users`（选项 A）
- **裁定**：选 **A**。DB 表名 `users`（对齐实体 `User` + admin 路径 `/users*`）；`GET /members/{id}` 仅是公开资料视图别名，路由层映射到 `users` 表并脱敏，**不要建 `members` 表**。
- **已落地**：`00-scaffold.md` 与 `01-auth.md` 的 `members` 引用已改 `users`。
