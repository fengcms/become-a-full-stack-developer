## 使用与替换流程（出图后）

1. 复制对应提示词 → 豆包生图 → 挑选满意的一张。
2. 上传到 CSDN 图床（或你惯用的图床），拿到图片 URL。
3. 在文章的对应位置，把 `{{IMG:图名}}` 整段替换为 `![](图片URL)`。
4. 八篇文末的 `{{IMG:CTA-订阅专栏}}` 同样替换为 CTA 图 URL。
5. 替换前 token 一律保留，便于批量检索未替换项（`grep '{{IMG:' articles/`）。
