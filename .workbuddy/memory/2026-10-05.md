## 🔴 追加：坐实一个会假阴性的 grep 工具坑
核查过程中发现本环境 `grep`（WorkBuddy brokered shim）**不支持 BRE `\|` 交替**：
- `grep -c "M2-03-\|M2-05-" ARTICLES.md` → **0**（错误）
- `grep -cE "M2-03-|M2-05-" ARTICLES.md` → **2**（正确）
- `grep -c -e "M2-03-" -e "M2-05-" ARTICLES.md` → **2**（正确）

**这修正了本日上文的诊断**：当时把「裸 grep 报零残留」归因于「输出量过大被沙箱截断」，其实真因就是 `\|` 失效（同一条命令里的单模式项正常输出了 103 处，说明并未截断）。
**规程**：禁用 `\|`；用 `grep -E "a|b"` / `-e a -e b` / 内置 Grep 工具；「零残留」判定以 `check_links.py` [C] 项为准。
