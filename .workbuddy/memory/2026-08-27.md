## ⚠️ 重要发现：后端无"创建第一个管理员"的入口（生产级缺陷）

- 证据：`POST /register` 强制 `role:'member'`（`services/user.ts:309`）；提权 `PATCH /users/{id}` 需 `guard('admin')`（`routes/users.ts:46`）；迁移只种子化 `site_settings`，无 admin 种子；无 `SEED_ADMIN` 等环境变量。→ 鸡生蛋死锁：没有 admin 就无法造 admin。
- 影响：上线后无法创建首个 admin（除非手动改库）。冒烟脚本用"直插 DB"绕过，但**生产需要补种子机制**（如 `SEED_ADMIN_EMAIL/SEED_ADMIN_PASSWORD` 环境变量首个请求自动建 admin，或一次性 bootstrap 端点/脚本）。已向 owner 指出，待其决策是否立项。
- 注意：此发现不影响已冻结契约（属部署/运维层），但属真实产品缺口，建议记入待办。
